| 语法   | 源码语法、支持范围和静态语法限制           | [`syntax`](./syntax/index.md)       |
| 类型   | 类型身份、推导、兼容、转换和收窄           | [`types`](./types/index.md)         |
| 语义   | 表达式、语句、控制流和语言机制的可观察行为 | [`semantics`](./semantics/index.md) |
