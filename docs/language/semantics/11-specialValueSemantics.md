## 目标与边界

本规范定义一元 `void`、不正常完成、`unknown` 有限操作和 symbol 的用户可观察行为。静态类型规则见 [`../types/11-specialTypes.md`](../types/11-specialTypes.md)。

## 一元 `void`

`void expression` 先正常求值操作数、丢弃结果，再产生值和类型均为 `undefined` 的结果：

```ts
const result = void save(); // undefined
void 0; // undefined
```

操作数只求值一次，求值顺序、副作用、同步异常和异步操作启动必须保留。`void` 不吞掉异常或 Promise rejection，也不把函数值转换为 `() => void`。

结果未使用时不需要物化 `undefined`。常量可以折叠，但不能删除有副作用或可能失败的操作数。

## 无值返回

`void` 返回函数的表达式仍按 JavaScript 顺序求值，调用方不能观察返回载荷。`undefined` 返回函数产生可使用的单例值；内部零载荷优化不能改变这一差异。

任何函数调用都可以作为表达式语句忽略结果。该行为不改变函数值本身的返回类型。

## `never` 与不正常完成

`throw`、准确返回 `never` 的调用和已证明无正常出口的控制流终止当前路径。它们仍保留已经发生的副作用和异常传播。

表达式按语法规定的顺序求值。必经子表达式不能完成时，后续项不执行：

```ts
consume(fail(), sideEffect());
// sideEffect 不执行
```

短路、条件表达式与可选链只终止实际进入 `never` 子表达式的路径。可能抛出不等于静态返回 `never`；正常完成和异常完成保持独立。

## `unknown` 的有限值操作

`unknown` 在收窄前只允许保持动态表示的复制、存储、传参、返回，以及规范授权的标签检查。

- 严格空值比较只检查动态标签。
- `unknown === unknown` 按当前动态成员执行 JavaScript 严格相等：引用按身份，基础值按值。
- 原生数值动态标签不同不自动表示值不等；跨数值类型的精度与严格相等算法由 T50 定义。
- `unknown ?? fallback` 只检查空值标签，左侧非空时返回原动态值。
- 普通非空值必须先显式打包，才能与 `unknown` 进行动态严格比较或作为 `??` 右侧。
- `unknown` 不能直接用于 truthiness。

这些操作不扫描对象字段或容器内容，不调用用户代码。

## Symbol 值

每次 `Symbol()` 求值创建与所有既有 symbol 不同的新身份。描述不参与身份或相等：

```ts
Symbol("x") === Symbol("x"); // false
```

省略描述或传入 `undefined` 表示无描述；数值描述使用 JavaScript Number 文本格式。其他类型不执行 `ToPrimitive` 或隐式字符串转换。当前描述只用于诊断和调试，不可由源码读取。

symbol 的可观察行为为：

| 操作             | 行为                   |
| ---------------- | ---------------------- |
| 复制、传参、返回 | 保持身份。             |
| `typeof value`   | `"symbol"`。           |
| `===`、`!==`     | 比较身份，不比较描述。 |
| truthiness       | 始终 truthy。          |
| `switch`         | 按身份匹配。           |

不支持算术、大小比较、字符串拼接、模板插值或隐式数值/字符串转换。`new Symbol()` 编译错误，与 JavaScript 不可构造行为一致。

## 性能语义

一元 `void`、`never` 终止和 symbol 相等不装箱、不分配。`Symbol()` 是显式 O(1) 身份分配边界；未使用 symbol 的程序不承担身份分配或查询成本。

`unknown` 的标签操作成本只由显式动态值承担，不传播到普通静态值。

## 语义测试

至少覆盖一元 `void` 单次求值与异常、void/undefined 返回差异、`never` 后续项不执行、unknown 空值与严格比较、symbol 唯一身份、描述不参与相等、truthiness 和禁止隐式转换。
