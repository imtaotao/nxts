## 核心值语义

普通数组满足以下可观察不变量：

| 不变量   | 行为                                                         |
| -------- | ------------------------------------------------------------ |
| 稠密     | `0 <= index < length` 的每个位置都有一个元素值，不存在空洞。 |
| 可变长度 | 受支持的数组操作可以追加、删除或截断元素。                   |
| 引用身份 | 赋值、传参和返回只复制引用；`===` / `!==` 比较数组身份。     |
| 稳定身份 | 扩容不能改变数组对象身份。                                   |
| 静态成员 | 数组方法不能被覆盖或作为动态属性修改。                       |

数组不是普通动态对象或字典。不能添加自定义属性、修改原型、删除单个元素或通过越界写入创建空洞。

## 赋值、别名与复制

赋值、参数传递和返回保留别名：

```ts
const first = [1, 2];
const alias = first;
alias.push(3);
// first 也是 [1, 2, 3]
```

数组 spread 和解构 rest 创建新的数组身份并执行浅拷贝。标准库中哪些方法创建新数组由[数组标准库](../../stdlib/2-array.md)定义。对象元素只复制引用。

编译器证明新身份、别名和写入均不可观察时，可以消除复制或转移缓冲区，但程序观察到的结果仍必须等价于创建新数组。

## 长度

`length` 的有效范围为 `0..2^31-1`：

```ts
values.length = 0; // 清空
values.length = shorter; // 截断
values.length = larger; // 编译错误或 RangeError
```

| 目标长度           | 行为                       |
| ------------------ | -------------------------- |
| 小于当前长度且非负 | 截断，所有别名观察到变化。 |
| 等于当前长度       | 无操作。                   |
| 大于当前长度       | 禁止，避免创建空洞。       |
| 负数               | 禁止。                     |

非法值静态可知时编译错误；动态值在显式长度赋值处抛出 `RangeError`，数组保持不变。

`length = 0` 清空同一个数组。旧元素不再属于数组，也不能继续保活仅由这些元素引用的对象。容量不可观察，不提供 `capacity`、`free` 或 `shrinkToFit`。

## 索引行为

读取有效索引返回对应元素；越界读取返回 `undefined`：

```ts
const value = values[index];
```

越界写入不能追加或创建空洞。静态可知时编译错误；动态越界写入抛出 `RangeError`，数组保持不变。追加只能使用[数组标准库](../../stdlib/2-array.md)明确支持的增长操作。

负索引的普通方括号读取返回 `undefined`。标准方法的起止位置、删除数量和深度参数由[数组标准库](../../stdlib/2-array.md)定义。

## 标准库修改操作

修改方法的存在性、返回身份、失败和逐方法行为只由[数组标准库](../../stdlib/2-array.md)定义。所有被支持的方法都必须保持本规范的稠密性、稳定数组身份、别名可见性、长度上限和失败原子性。

## 只读视图

只读数组与可变数组可以观察同一个底层数组身份。`readonly` 不冻结数组；其他可变别名的修改仍然可见：

```ts
const mutable: i32[] = [1, 2];
const view: readonly i32[] = mutable;

mutable.push(3);
// view.length === 3
```

只读视图本身不能执行索引写入或 `length=`。只读接收者可用的方法及其结果类型由[数组标准库](../../stdlib/2-array.md)定义。

Nxts 不提供 `Object.freeze`、`Object.seal`、`Object.preventExtensions` 及其状态查询 API。

## 标准库回调

回调顺序、短路、异常、异步结果和同数组结构修改限制属于[数组标准库](../../stdlib/2-array.md)的方法契约。T58 提供副作用摘要；实现不能为这些检查给普通数组增加版本字段、迭代锁或运行时修改检查。

## 遍历

`keys()`、`values()`、`entries()` 和 `ArrayIterator<T>` 的公开契约由[数组标准库](../../stdlib/2-array.md)与 T60 定义，不要求公开 `Symbol.iterator`。

显式 `for` 和 `for...of` 允许结构性修改数组：

- 普通 `for` 按源码条件重新读取长度。
- `for...of` 按 JavaScript 数组迭代规则观察当前长度。
- 可能修改结构时必须重新读取长度和缓冲区。
- 证明无结构修改时可以提升长度并消除检查。

数组禁止 `for...in`，因为 JavaScript 字符串键与 Nxts `i32` 索引模型冲突。

## 对象反射

数组只向对象反射暴露当前稠密索引，不暴露容量、缓冲区或方法成员。`Object.keys`、`Object.values` 和 `Object.entries` 的返回类型、结果身份和逐 API 行为由[对象标准库](../../stdlib/4-object.md)定义。

## 解构

普通数组解构按索引顺序读取。不存在的位置产生 `undefined`；默认值在结果为 `undefined` 时求值：

```ts
const [first, second = fallback] = values;
```

解构空位只跳过位置，不创建数组空洞。`...rest` 创建新的稠密浅拷贝数组；不含 rest 的解构可以直接降低为索引读取。

元组的精确位置规则由 [`T35`](../types/22-tupleTypes.md) 定义。

## 递归与多维数组

数组可以形成可观察的递归引用：

```ts
type Nested = i32 | Nested[];

const root: Nested[] = [];
root.push(root);
```

`T[][]` 表示外层数组保存内层数组引用。每一行可以具有不同长度、身份和独立容量，不具有连续二维矩阵语义。

标准库批量创建二维数组时，重复引用还是逐行调用生成器由对应 API 契约明确区分，不能隐式克隆引用对象。

## 失败行为

| 场景                | 结果                                    |
| ------------------- | --------------------------------------- |
| 越界读取            | 返回 `undefined`。                      |
| 越界写入            | 静态可知时编译错误，否则 `RangeError`。 |
| `length` 负数或增大 | 静态可知时编译错误，否则 `RangeError`。 |
| 超过最大长度        | `RangeError`，数组保持原值。            |

标准方法自己的空输入、回调和比较器失败由[数组标准库](../../stdlib/2-array.md)定义。内存分配失败由 T46 统一定义，不作为普通数组结果类型的分支。静态诊断不得依赖优化级别改变程序接受结果。

## 性能语义边界

以下优化不能改变数组语义：

- 消除已证明安全的边界检查。
- 内联已知回调并消除不逃逸闭包和迭代器。
- 已知长度时一次分配。
- 对同布局元素使用批量复制。
- 在身份和别名不可观察时消除数组分配或结果复制。
- 对封闭数组联合生成按既有判别信息分派的同构专用循环。

普通同构数组不能为未使用的接口、动态值、字典、稀疏数组或动态原型能力支付运行时成本。

## 与 JavaScript 的行为差异

| 主题       | JavaScript                        | Nxts                             |
| ---------- | --------------------------------- | -------------------------------- |
| 空洞       | 支持稀疏数组、越界增长和 `delete` | 普通数组始终稠密，相关写法拒绝。 |
| 越界读取   | 返回 `undefined`                  | 保持一致。                       |
| 越界写入   | 可以增长并形成空洞                | 拒绝或抛出 `RangeError`。        |
| 原型与属性 | 方法可替换，可添加属性            | 静态方法解析，无自定义属性。     |
| `for...in` | 产生字符串键                      | 数组拒绝，使用静态迭代 API。     |
| 动态冻结   | 支持                              | 不支持，使用静态 `readonly`。    |
| TypedArray | 标准内建类型                      | 不作为普通数组能力。             |

标准数组方法与 JavaScript 的差异由[数组标准库](../../stdlib/2-array.md)集中记录。支持范围内的数组身份、求值顺序、异常和浅拷贝行为应与 JavaScript 一致。

## 语义测试

| 场景                   | 预期                           |
| ---------------------- | ------------------------------ |
| 数组赋值后通过别名写入 | 原数组观察到修改。             |
| `array.length = 0`     | 同一数组身份被清空。           |
| 动态越界读取           | `undefined`。                  |
| 动态越界写入           | `RangeError` 且数组不变。      |
| 显式 `for` 内增长数组  | 合法，按循环条件重新读取长度。 |
| 数组 `for...in`        | 编译错误。                     |
| 不可达自引用数组       | 可由 T46 回收。                |
