# 对象语义

- 覆盖能力：T26、T27
- 规范状态：已定稿
- 文档顺序：4

## 目标与边界

本规范定义普通对象的引用身份、属性存在性、`in`、枚举、`for...in`、展开和原型边界。

静态形状由[对象类型](../types/15-objectTypes.md)定义，`Object.*` API 由[对象标准库](../../stdlib/4-object.md)定义，描述符和反射辅助算法由[对象运行时](../../runtime/objects/3-objectRuntime.md)定义。

## 引用身份

对象赋值、传参和返回传递引用，不复制字段：

```ts
const a = { x: 1 };
const b = a;

b.x = 2;

a.x === 2; // true
a === b; // true
```

每次对象字面量求值创建独立身份：

```ts
const a = { x: 1 };
const b = { x: 1 };

a === b; // false
```

`===` 和 `!==` 比较身份。栈分配、标量替换和分配消除不得改变共享写入或身份比较结果。

## 属性存在状态

可选属性必须区分缺失与存在但值为 `undefined`：

```ts
type Options = {
  value?: string | undefined;
};

const a: Options = {};
const b: Options = { value: undefined };

a.value === b.value; // true
Object.hasOwn(a, 'value'); // false
Object.hasOwn(b, 'value'); // true
```

写入缺失的可写可选属性会使其存在；赋值为 `undefined` 仍保持存在。`delete` 清除存在状态，且缺失属性不能继续保活只由旧值引用的对象：

- 读取继续得到 `undefined`。
- `in`、`Object.hasOwn` 和枚举观察到缺失。
- 再次写入时重新成为自身属性。

必需属性和只读可选属性不能删除。

## `in`

`in` 检查自身属性、静态类继承成员和语言定义的固定根成员：

```ts
function contains(options: { value?: string }, key: string) {
  return key in options;
}
```

右操作数必须在求值前排除 `null` 与 `undefined`。普通对象 key 必须是 `string`，不执行 JavaScript `ToPropertyKey`。

| key 与形状关系   | 结果                         |
| ---------------- | ---------------------------- |
| 必需自身属性     | 可折叠为 `true`。            |
| 可选自身属性     | 检查存在状态。               |
| 静态继承成员     | 可折叠为 `true`。            |
| 完整形状中不存在 | 可折叠为 `false`。           |
| 动态字符串       | 查询共享描述符和存在状态。   |
| 联合对象         | 根据联合判别选择成员描述符。 |

接口值可能由具有额外成员的对象实现，因此接口契约未声明的 key 仍需查询底层描述符。接口必需成员可以折叠为 `true`，可选成员检查具体状态。

常量折叠必须保留左右操作数求值顺序、副作用和失败。动态 `in` 不分配内存，也不能因此创建实例属性表。

字符串字面量 key 可以参与控制流收窄：

- 必需或继承成员只保留能够拥有该成员的联合分支。
- 完全不含该成员的分支只保留在 `false` 路径。
- 可选成员可以出现在两条路径，`true` 路径增加“属性存在”事实。
- 宽 `string` 只返回 `boolean`。

## 属性枚举顺序

自身可枚举字符串属性保持 JavaScript 顺序：

1. 数组索引形式键按数值升序。
2. 其他字符串键按属性首次存在顺序。

数组索引键是整数 `n` 的规范十进制字符串，其中 `0 <= n < 2^32 - 1`。除 `"0"` 外不允许前导零；负数、`"-0"`、非整数和 `"4294967295"` 均为普通字符串键。

对象创建时存在的属性按字面量或初始化求值顺序建立。缺失可选属性第一次写入时追加到非索引键顺序；后续修改不移动。删除后重新写入会作为新的首次存在追加。

不同分配点即使具有相同静态形状，也可以具有不同初始枚举顺序。

## `for...in`

`for...in` 零分配遍历自身可枚举字符串属性：

```ts
for (const key in options) {
  const value = options[key];
}
```

普通对象不支持动态原型属性，类方法与固定根成员不可枚举，因此键集合与 `Object.keys` 一致。

循环变量类型：

| 对象类别       | key 类型                           |
| -------------- | ---------------------------------- |
| 精确对象       | 可能存在的自身可枚举键字面量联合。 |
| 封闭对象联合   | 各成员可能键的联合。               |
| T30 字典视图   | `string`。                         |
| 无索引签名接口 | `string`，不能仅凭接口契约索引。   |

循环已经证明当前可选属性存在，索引结果不因缺失额外加入 `undefined`；属性声明本身包含 `undefined` 时仍保留。

`for...in` 的 runtime 遍历和 `for...of Object.keys(object)` 融合条件由 [`3-objectRuntime.md`](../../runtime/objects/3-objectRuntime.md) 与 [`1-loweringStrategies.md`](../../compiler/optimizer/1-loweringStrategies.md) 定义，不能改变键集合、顺序、求值或循环体修改对象的行为。

## 对象展开

对象展开创建新的普通对象，并复制实际底层对象的全部自身可枚举字段：

- 不按静态接口或基类视图裁剪。
- 不复制类身份、方法和访问器。
- 引用字段执行浅拷贝。
- 结果具有独立对象身份。
- 属性创建顺序遵循展开源与后续属性的源码求值顺序。

精确结果类型和 spread 冲突由 T52 定义。身份和写入不可观察时可以消除结果分配。

## 静态继承与原型边界

普通对象不支持运行时创建、替换或修改原型链：

```ts
Object.create(prototype);
Object.setPrototypeOf(value, prototype);
value.__proto__ = prototype;
Constructor.prototype.run = run;
```

类只通过静态 `extends` 建立单继承。接口 `extends` 只建立静态契约组合，不产生原型链。

带字典上下文的 `Object.create(null)` 是 T30 空字典构造入口，不建立普通对象原型链。

## 默认字符串行为

普通对象默认 `toString()` 返回 `"[object Object]"`，不枚举字段。该能力的标准声明由[对象标准库](../../stdlib/4-object.md)定义。

默认方法静态解析、不可覆盖为普通对象实例属性且不可枚举，不要求对象携带方法表。

## 代理边界

当前不支持 JavaScript `Proxy`。普通对象不能被透明代理冒充，函数接收普通对象时不执行代理判断。

未来代理能力必须使用显式类型和表示，独立定义兼容、异常、GC 与 ABI。它不能放宽普通对象固定形状，也不能让普通对象预留 tag、隐藏字段或动态分派。

## 性能语义边界

- 普通字段访问不查询描述符。
- 动态 `in`、枚举和 `Object.*` 只在显式使用时支付成本。
- 可选属性首次存在可以更新实例级顺序记录，但不能改变固定字段访问结果。
- 未形成字典视图的对象不创建动态扩展表。
- 反射专门化和循环融合不能改变结果数组身份可观察性、顺序或循环体修改行为。

顺序记录和字段布局分别由[对象运行时](../../runtime/objects/3-objectRuntime.md)与[类型运行时表示](../../compiler/representation/1-typeRepresentation.md)定义。

## 与 JavaScript 的行为差异

| 主题             | JavaScript                   | Nxts                        |
| ---------------- | ---------------------------- | --------------------------- |
| 引用身份         | 对象引用语义                 | 保持一致。                  |
| 自身属性枚举顺序 | 索引键升序，其他键按首次存在 | 保持一致。                  |
| 动态新增属性     | 允许                         | 普通对象拒绝；使用字典。    |
| 动态原型         | 允许                         | 拒绝。                      |
| 属性描述符       | 支持                         | 普通对象拒绝。              |
| Proxy            | 支持透明拦截                 | 当前拒绝。                  |
| 动态冻结         | 支持                         | 拒绝，使用静态 `readonly`。 |

## 语义测试

| 场景                           | 预期                                            |
| ------------------------------ | ----------------------------------------------- |
| 两次对象字面量求值             | 身份不同。                                      |
| 对象赋值后通过别名写入         | 原引用观察到写入。                              |
| 可选属性缺失与显式 `undefined` | 读取相同，存在性不同。                          |
| 删除并重加可选属性             | 存在状态和枚举顺序正确。                        |
| 字面量 `in`                    | 保留求值后折叠。                                |
| 动态 `in`                      | 查询描述符，不分配。                            |
| `for...in`                     | 与 `Object.keys` 键集合和顺序一致，不分配数组。 |
| 对象展开接口或基类视图         | 复制实际自身可枚举成员。                        |
| 动态原型或 Proxy               | 编译错误。                                      |
