## 值绑定与引用身份

类声明同时产生构造器值。类实例和类构造器均使用引用身份：

```ts
class User {}

const A = User;
const B = User;

A === B; // true
new User() === new User(); // false
```

实例赋值、传参、返回和派生类到基类转换保留同一对象身份，不复制或裁剪字段：

```ts
class Animal {}
class Dog extends Animal {}

const dog = new Dog();
const animal: Animal = dog;

dog === animal; // true
```

只有在身份、别名和逃逸均不可观察时，优化器才能消除类或实例分配。

## 类声明与类表达式求值

模块级类声明求值一次并保持稳定类身份。局部类声明和类表达式每次执行到对应表达式时产生新的类身份：

```ts
function makeClass() {
  return class Item {};
}

const A = makeClass();
const B = makeClass();

A === B; // false
```

不同求值产生的类可以共享布局模板和方法代码，但不能合并：

- 构造器身份。
- 静态字段状态。
- 捕获环境。
- `name` 等与本次类值相关的元数据。

类方法和字段初始化器可以引用外层词法绑定。多个实例共享同一次类求值得到的捕获环境；不同类求值不能共享可变捕获身份。TDZ、遮蔽和名称绑定由 T57 定义，闭包生命周期由 T58 定义。

## 实例初始化顺序

声明字段在所属类层级开始初始化时建立自身属性。每个类层级按以下顺序执行：

| 顺序 | 动作                                                                     |
| ---: | ------------------------------------------------------------------------ |
|    1 | 求值派生构造器中 `super(...)` 前允许的表达式；期间不能使用 `this`。      |
|    2 | `super(...)` 完整构造基类层级。                                          |
|    3 | 当前层参数属性按参数顺序写入。                                           |
|    4 | 当前层实例字段初始化器按声明顺序求值并写入。                             |
|    5 | 执行构造器中 `super(...)` 后的剩余主体；基类构造器直接进入当前层初始化。 |

字段初始化器的副作用和异常保持源码顺序。物理字段偏移可以重排，但不能改变初始化顺序、属性首次存在顺序或覆盖结果。

派生类重声明同名字段时复用原属性。派生初始化器在基类构造完成后写回该属性，不创建第二个属性，也不改变其枚举位置。

## 可选字段存在性

无初始化器的 `field?: T` 在所属类层级初始化时建立自身属性，初始值为 `undefined`：

```ts
class Options {
  cache?: string;
}

const options = new Options();

Object.hasOwn(options, "cache"); // true
Object.keys(options); // ["cache"]
options.cache; // undefined
```

写入 `undefined` 保持属性存在。对可写可选字段执行 `delete` 后，属性变为缺失：

- `in` 和 `Object.hasOwn` 返回不存在。
- `Object.keys` 和对象展开不包含该属性。
- 再次写入时属性重新存在，并按 JavaScript 属性顺序规则获得新的非索引键顺序位置。

运行时必须区分“缺失”和“存在但值为 `undefined`”。普通无可选字段类不承担可选状态成本。

## `readonly` 行为

`readonly` 只限制静态写权限，不冻结实例或字段引用。通过合法可变别名发生的内部对象修改仍然可见。

类实例不调用 `Object.freeze`，也不保存动态冻结状态。构造完成后无需为 `readonly` 字段执行运行时写入检查。

## 构造器求值

类构造器只能通过 `new` 执行。已知类与动态构造器变量必须保持相同的参数求值顺序和实例初始化语义。

没有显式构造器时：

| 类别   | 行为                                         |
| ------ | -------------------------------------------- |
| 基类   | 执行当前层字段初始化。                       |
| 派生类 | 把参数类型化转发给基类，再执行派生层初始化。 |

转发不创建 `arguments` 对象或动态 rest 数组。派生构造器在 `super(...)` 返回后才能访问实例。

裸 `return;` 正常结束构造。Nxts 不支持 JavaScript 构造器返回替代对象的行为。

## `new.target`

构造器中的 `new.target` 是本次构造使用的实际类值：

```ts
class Base {
  constructor() {
    new.target; // new Base() 时为 Base，new Derived() 时为 Derived
  }
}

class Derived extends Base {}

new Derived();
```

已知具体 `new` 可以把结果折叠为静态类值。动态构造从现有类描述符取得身份，不增加通用类型检查。词法箭头函数可以捕获该值，逃逸成本由 T58 定义。

## 构造失败

字段初始化器、基类构造器或构造器主体抛出异常时：

| 行为           | 结果                                     |
| -------------- | ---------------------------------------- |
| 后续初始化     | 立即停止。                               |
| 部分实例       | 不返回给调用方；未泄漏时最终由 GC 回收。 |
| 字段回滚与析构 | 不执行隐式回滚、析构或 finalizer。       |
| 外部资源       | 使用显式 `try` / `finally` 和资源 API。  |
| 异常传播       | 由 T61 定义。                            |

正常构造路径不能为可能抛错预付动态检查或事务回滚成本。

## 方法覆盖与 `super`

普通实例调用根据实际运行时类选择最派生覆盖。`super.method(...)` 直接调用词法父类实现：

```ts
class Animal {
  speak(): string {
    return "animal";
  }
}

class Dog extends Animal {
  speak(): string {
    return `${super.speak()}:dog`;
  }
}
```

已知目标直接调用与多态槽位调用必须具有相同结果、接收者身份、参数求值顺序和异常行为。方法提取不会自动绑定实例；箭头函数字段具有独立的自动绑定函数值语义。

## 访问器

getter 在读取成员时执行，setter 在写入成员时执行。访问器不是实例自身属性，不进入 `Object.keys` 或对象展开。

已知接收者直接调用访问器与多态调用必须保持相同副作用和异常顺序。Nxts 不提供运行时安装 getter、setter 或修改属性描述符的路径。

## 箭头函数字段

箭头函数字段是实例自身、可枚举属性，每个实例通常具有独立函数身份：

```ts
class Button {
  click = () => this;
}

const first = new Button();
const second = new Button();

first.click === second.click; // false
```

普通方法由类共享且不可枚举。只捕获 `this` 的箭头字段可以使用更紧凑表示，或在身份不可观察时消除函数值，但不能改变 `===`、字段可写性和枚举结果。

## TypeScript `private` 的运行时可见性

`private` 与 `protected` 是静态访问控制，不提供运行时隐藏：

- private 实例字段仍是自身可枚举字段。
- `Object.keys`、对象展开和序列化可以观察运行时键和值。
- 反射结果不根据当前静态访问位置裁剪。

访问控制不能通过动态索引、反射或类型断言在源码中绕过，但运行时枚举结果与 JavaScript 普通字段一致。

## 接口视图与身份

类实例形成接口视图时保留底层对象身份：

```ts
const user = new User();
const named: Named = user;

user === named; // true
```

接口视图不裁剪实例字段，不复制对象，也不改变实际类身份。通过接口调用的结果必须与直接类调用一致。

## 静态字段继承

静态字段、方法和访问器参与 JavaScript 类构造器继承语义，但不依赖可修改原型链实现。

继承静态字段遵循“读取继承值、首次写入创建派生类自身字段”：

```ts
class Base {
  static value = 1;
}

class Derived extends Base {}

Derived.value; // 1
Derived.value = 2;
Base.value; // 1
Derived.value; // 2
```

派生类显式声明同名静态字段时，从派生类初始化开始即具有自身字段。删除可写可选派生静态字段后，同名基类字段可以重新成为继承读取结果。

静态方法和访问器可以继承与覆盖。通过构造器变量调用时选择实际类的静态覆盖；`super.staticMember` 访问词法父类成员。

## 静态初始化顺序

静态字段初始化器和静态块按类体源码顺序执行。基类静态初始化必须先于派生类：

```ts
class Registry {
  static first = createFirst();

  static {
    register(Registry.first);
  }

  static second = createSecond();
}
```

模块级类初始化一次。局部类和类表达式每次实际求值都执行该次类身份的静态字段初始化器和静态块。

静态块可以访问 `this`、当前类静态成员和 `super.staticMember`，不能使用 `await`、`yield`、`return`、`super()` 或 `new.target`。

模块循环、顶层执行顺序和初始化失败缓存由 T55 定义；异常传播由 T61 定义。

## 计算成员名

编译期常量成员名按固定成员处理，不增加运行时查找。宽动态计算键在每次类求值时执行一次，不在每个实例上重复求值：

```ts
const createBagClass = (dynamicKey: string) => {
  class Bag {
    [key: string]: string;
    [dynamicKey] = "value";
  }

  return Bag;
};
```

动态字段的写入、删除、枚举和键冲突复用 T30。没有显式索引签名的类不获得动态字段行为。

## 实例枚举与对象展开

| 成员                                  | 自身属性 | 可枚举 |
| ------------------------------------- | -------- | ------ |
| public / protected / private 实例字段 | 是       | 是     |
| 参数属性                              | 是       | 是     |
| 箭头函数字段                          | 是       | 是     |
| 基类实例字段                          | 是       | 是     |
| 普通实例方法                          | 否       | 否     |
| getter / setter                       | 否       | 否     |
| 默认 `constructor`                    | 否       | 否     |

`Object.keys`、`Object.values`、`Object.entries`、`for...in`、对象展开和序列化使用实际运行时实例的自身可枚举成员，不按静态基类或接口视图裁剪。

枚举顺序保持 JavaScript 规则：

- 数组索引形式键按数值升序。
- 其他键按属性首次存在顺序。
- 基类先建立的字段位于派生新增普通字符串字段之前。
- 派生重声明写回已有属性，不移动顺序。
- 参数属性与当前层字段按初始化顺序建立。

对象展开复制全部自身可枚举字段并创建普通对象，不复制类身份、方法和访问器。

## `constructor`

类实例提供只读 `constructor` 访问，返回实际运行时类身份：

```ts
const animal: Animal = new Dog();
animal.constructor === Dog; // true
```

默认 `constructor` 不占实例字段：

```ts
Object.hasOwn(animal, "constructor"); // false
"constructor" in animal; // true
```

实例不能覆盖或删除默认 `constructor`。动态索引签名中的同名键遵循 T30 遮蔽和诊断规则。

`instance.constructor` 不提供可构造签名；动态构造必须显式持有构造器值。

## 类构造器 `name` 与 `length`

类构造器默认具有只读、不可枚举的 `name` 和 `length` 元数据：

- `name` 使用 JavaScript 类声明和类表达式名称推导。
- `length` 使用实现构造器中第一个默认参数之前的参数数量。
- 可选参数计数，rest 不计数。
- 构造器重载读取唯一实现签名。

默认元数据不能赋值、删除或通过属性描述符修改。类可以显式声明同名静态字段或访问器；此时使用普通静态成员语义，编译器内部调试身份单独保存。

静态成员名 `prototype` 编译错误，类构造器的 `.prototype` 不属于可访问 API。

## 默认对象能力

类实例的默认 `toString` 和支持的 `Object` API 由[类内建能力](../../stdlib/3-classBuiltins.md)定义。类不继承隐藏的用户可见 `Object` 根类。

不提供完整 `Object.prototype`、动态原型反射或 `__proto__` 行为。

## `instanceof`

`instanceof` 按运行时类身份和静态继承关系判断：

```ts
function matches(value: Animal, Ctor: typeof Animal): boolean {
  return value instanceof Ctor;
}
```

Nxts 不调用 `Symbol.hasInstance`，不读取 `.prototype`，也不观察动态原型修改。动态构造器检查使用实际类描述符与祖先摘要。

已知类检查可以常量折叠，但必须保持同一布尔结果。接口不能作为 `instanceof` 目标。

## 泛型类的运行时身份

所有 `Box<T>` 闭合实例共享同一个运行时类家族身份和静态状态。`instanceof Box` 不检查类型实参。

不同类型实参可以具有不同字段布局或专门化代码，但不能因此改变类身份比较、静态字段共享或 `instanceof` 结果。

## 生命周期

类实例使用 GC 管理，不要求手动释放。递归和循环类引用合法：

```ts
class Node {
  next?: Node;
}
```

Nxts 不提供手动 `free`、析构器、finalizer、WeakRef、FinalizationRegistry 或 `Symbol.dispose` 类协议。外部文件、句柄和连接使用显式资源 API 关闭，内存回收时机不是可观察类生命周期。

## 性能语义边界

以下优化必须保持类语义：

- 直接调用、去虚拟化和方法内联。
- 栈分配、标量替换和实例分配消除。
- 类描述符与捕获环境消除。
- 可选字段分支消除。
- 固定类枚举路径专门化。
- 构造与字段初始化写入合并。

这些优化不能改变对象或类身份、初始化顺序、异常边、字段枚举顺序、静态继承结果或捕获环境共享。

普通类不能为未使用的动态字段、捕获、静态继承存在状态、异步或生成器能力支付实例空间或分支成本。

## 与 JavaScript 的行为差异

| 主题                   | JavaScript                       | Nxts                           |
| ---------------------- | -------------------------------- | ------------------------------ |
| 动态 `extends` / mixin | 支持表达式                       | 拒绝。                         |
| `extends null`         | 支持无原型类                     | 拒绝。                         |
| 构造器返回对象         | 可以替换实例                     | 拒绝带值返回。                 |
| 原型和属性描述符       | 可以动态修改                     | 拒绝。                         |
| `Symbol.hasInstance`   | 可以自定义                       | 拒绝。                         |
| 类表达式与捕获         | 支持                             | 保持每次求值身份与捕获语义。   |
| 方法与字段枚举         | 字段可枚举，方法和访问器不可枚举 | 保持一致。                     |
| 可选类字段             | 存在且初值为 `undefined`         | 保持一致，并区分删除后的缺失。 |
| 内建类继承             | 多数构造器可尝试继承             | 仅可信白名单。                 |

支持范围内的初始化、身份、静态继承、枚举、异常和捕获结果必须与 JavaScript 严格模式一致。

## 失败行为

| 场景                            | 结果                                    |
| ------------------------------- | --------------------------------------- |
| 构造或字段初始化表达式抛出异常  | 停止后续初始化并按 T61 传播。           |
| 静态初始化表达式抛出异常        | 停止当前类初始化；缓存规则由 T55 定义。 |
| 内存分配失败                    | 进入 T46 的统一失败路径。               |
| 类布局、方法表或构造 ABI 不匹配 | 链接或模块加载前失败。                  |

类型错误场景由[类类型](../types/23-classTypes.md)定义。Debug、Release 和优化级别不能改变静态接受结果或可观察行为。

| 场景                           | 预期                             |

| 模块类多次读取                 | 类身份稳定。                     |

| 基类与派生字段初始化           | 按规范层级和源码顺序。           |

| 删除可写可选字段               | 属性变为缺失。                   |

| private 字段执行 `Object.keys` | 运行时仍可枚举。                 |
| 静态字段继承后首次派生写入     | 创建派生类自身静态字段。         |

| 动态计算成员名                 | 每次类求值执行一次。             |
| 对象展开类实例                 | 只复制实际自身可枚举字段。       |

| 不可达循环实例                 | 可由 T46 回收。                  |
