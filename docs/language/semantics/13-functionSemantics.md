## 目标与边界

本规范定义同步普通函数、箭头函数和方法的用户可观察行为，包括默认参数求值、rest 数组身份、接收者、函数身份及重载的运行时边界。静态签名、方差和重载检查由 [`20-functionTypes.md`](../types/20-functionTypes.md) 定义；闭包、异步函数和生成器分别由 T58–T60 定义。

## 默认参数

默认值只在参数缺失或实参为 `undefined` 时求值；传入 `null` 不触发默认值。默认表达式从左到右求值，可以读取外层绑定、方法接收者和已经完成初始化的前置参数：

```ts
function range(start = 0, end = start + 10): void {}
```

默认表达式不能读取自身、后续参数或函数体局部声明。JavaScript 可能只在实际执行该表达式时抛出 `ReferenceError`，Nxts 将其提前为编译错误；被接受表达式的求值顺序和副作用仍与 JavaScript 一致。

默认参数位于必选参数之前时，调用方必须保留槽位并显式传入 `undefined` 才能触发默认值：

```ts
function open(mode = 'read', path: string): void {}

open(undefined, 'data.txt');
```

进入函数体后，默认参数已经初始化为其非空缺类型。

## Rest 参数

rest 参数在函数体内表现为一个新的可变数组。即使没有尾部实参，语义上也存在独立空数组；rest 数组不能与调用点 spread 来源共享可变身份。

编译器可以在数组身份、写入和逃逸均不可观察时栈分配、标量替换或消除该数组。发生逃逸或身份可观察时，必须创建独立 GC 数组。普通非 rest 函数不承担数组创建或动态实参数组成本。

## 方法与接收者

方法通过成员调用接收静态接收者，函数属性保存独立函数值。直接方法调用不创建绑定闭包；提取方法不会自动绑定原对象：

```ts
const run = service.run;
run(1); // 编译错误：缺少接收者

const boundRun = (value: i32): i32 => service.run(value);
```

显式 `this` 伪参数不属于源码实参；箭头函数使用词法 `this`。未建立接收者的普通函数使用动态 `this` 属于编译错误。接收者捕获、环境逃逸和 GC 由 T58 定义。

## 函数身份

每次实际执行函数创建表达式都会产生独立函数身份；赋值和别名保留原身份：

```ts
const first = (): i32 => 1;
const second = (): i32 => 1;
const alias = first;

first === second; // false
first === alias; // true
```

静态兼容、返回协变、参数数量适配和重载入口选择不能改变函数身份。编译器仅在身份不可观察时消除函数值。

## 重载运行时边界

重载候选和实现签名只存在于编译期。调用点完成解析后只执行选中的单一类型化入口；运行时不遍历候选，不根据动态值重新选择重载，也不复制实现体。

机器表示不同的重载入口仍共享同一函数身份、实现、`name` 和 `length`。同一个运行时参数元组不能因为调用方静态类型不同而观察到不同业务行为。

## 与 JavaScript 的边界

| 能力         | Nxts 行为                                |
| ------------ | ---------------------------------------- |
| 精确参数调用 | 缺失必选参数或多余实参在编译期拒绝。     |
| `arguments`  | 不创建，也不形成函数作用域特殊绑定。     |
| 自动方法绑定 | 不提供；使用箭头函数显式捕获接收者。     |
| 动态调用分派 | 不提供通用动态实参数组或运行时重载解析。 |
| 函数动态属性 | 函数值不是普通对象或字典。               |

公开函数属性和方法白名单见 [`9-function.md`](../../stdlib/9-function.md)。
