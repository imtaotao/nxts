# 字典语义

- 任务编号：T30
- 规范状态：已定稿
- 文档顺序：5

## 目标与边界

本规范定义字典 key 规范化、引用身份、缺失读取、写入、删除、存在检查、枚举、解构、rest 和 spread 的可观察行为。

静态类型由[字典类型](../types/18-dictionaryTypes.md)定义，哈希和扩容由[字典运行时](../../runtime/objects/4-dictionaryRuntime.md)定义，公开反射 API 由[对象标准库](../../stdlib/4-object.md)定义。

## key 规范化

字符串字典接受字符串 key。数值 key 使用 JavaScript Number 的规范属性字符串：

| 输入       | 规范 key     |
| ---------- | ------------ |
| `1`、`"1"` | `"1"`        |
| `-0`、`0`  | `"0"`        |
| `1.5`      | `"1.5"`      |
| `NaN`      | `"NaN"`      |
| `Infinity` | `"Infinity"` |

不执行对象级用户转换。常见非负整数 key 不要求分配临时字符串；完整数值格式化遵循 T13。

同一字面量中宽动态 key 冲突时，后一次写入覆盖。对象 spread 冲突同样由后来源覆盖，覆盖已有 key 不改变枚举位置。

## 引用身份

原生字典和对象字典视图都采用对象身份：

- 内容相同但独立创建的字典不相等。
- 赋值别名相等。
- 同一对象形成的不同字典视图相等。
- 比较视图只比较底层对象身份，不比较 witness、容量或扩展表地址。

对象形成字典视图不复制对象。通过字典写入固定成员或动态扩展对所有别名可见，但不扩大其他别名的静态类型。

## 缺失读取

缺失动态 key 返回 `undefined`，不能返回原生零值：

```ts
const dict: { [key: string]: i32 } = {};

dict["missing"]; // undefined
```

属性声明本身允许 `undefined` 时，存在状态仍独立：

- key 缺失。
- key 存在且值为 `undefined`。

这两种情况读取相同，但 `in`、`Object.hasOwn` 和枚举结果不同。

## 写入

写入已存在 key 更新值且不移动枚举位置。写入新 key 建立存在状态并按首次存在顺序加入枚举。

写入 `undefined` 在值类型允许时仍表示 key 存在。宽 key 可能覆盖固定成员或类方法时，所有别名观察到同一对象身份上的结果。

## 删除

删除行为：

| 目标             | 结果                                     |
| ---------------- | ---------------------------------------- |
| 可写动态 key     | 删除存在条目并返回 `true`。              |
| 不存在动态 key   | 返回 JavaScript `delete` 对应的 `true`。 |
| 可写可选固定成员 | 清除存在状态。                           |
| 动态自身 shadow  | 删除 shadow，可能重新暴露继承成员。      |

删除后重新插入按新的首次存在位置枚举。删除继承方法只移除可能存在的自身 shadow，不移除类描述符成员。

如果删除表达式结果未使用，后续阶段可以省略布尔值物化，但不能省略删除副作用。

## 对象字典视图的动态重叠

对象字典扩展状态可以记录：

- 新动态条目。
- 固定成员 shadow。
- 删除 tombstone。

发生可能重叠的写入或删除后，相关成员读取合并固定字段与扩展状态。没有发生重叠副作用的路径继续观察固定字段。

所有对象、接口和字典别名共享同一对象身份对应的扩展状态。

## `in` 与自身存在性

| 值类别       | `key in value`             | 自身存在查询         |
| ------------ | -------------------------- | -------------------- |
| 纯字典       | 当前存在条目。             | 当前存在条目。       |
| 对象字典视图 | 自身固定与动态成员。       | 自身固定与动态成员。 |
| 类字典视图   | 自身、基类成员和继承方法。 | 自身字段与动态成员。 |
| 接口字典视图 | 按底层具体值。             | 按底层具体值。       |

基类公共实例字段属于自身属性；继承方法不属于自身属性。动态 `in` 不逐级遍历父链。

存在检查后的读取可以复用同一次哈希探测。对象写入、key 重新赋值、可能删除的调用或别名副作用使结果失效。

`Object.hasOwn` 映射到上述自身存在查询；其公开签名和 API 行为由[对象标准库](../../stdlib/4-object.md)定义。

## 特殊 key

`"__proto__"`、`"constructor"` 和其他原型敏感 key 在字典中是普通数据 key：

- 不修改原型。
- 不访问继承构造器。
- 不触发额外运行时分支。

静态使用这些 key 会产生兼容性警告，说明与普通 JavaScript 对象行为不同。

## 枚举

字典只枚举实际存在的自身可枚举条目：

1. 数组索引形式字符串 key 按数值升序。
2. 其他字符串 key 按首次存在顺序。
3. 覆盖不移动位置。
4. 删除后重插按新的首次存在位置。

类字典视图不枚举继承方法。接口视图枚举底层实际成员，不按契约裁剪。

`for...in` 直接遍历，不要求创建 key 数组。`Object.keys`、`Object.values` 和 `Object.entries` 的结果类型、身份与缺失值处理由[对象标准库](../../stdlib/4-object.md)定义。循环期间修改规则由 T54 定义。

## 解构、rest 与 spread

```ts
const { name } = dict; // 缺失时 undefined
const { name = fallback } = dict;
const { [key]: value } = dict;
const { name, ...rest } = dict; // 新字典
```

对象 rest 和 spread 只复制自身可枚举条目，从左到右覆盖。`{ ...dict }` 创建新对象或字典身份，复杂度 O(n)；普通字典赋值或视图转换不复制。

具体左值、求值顺序和结果类型由 T52 定义。

## 性能语义边界

- 平均查找、写入和删除为 O(1)。
- 固定 key 未受动态重叠时可以恢复为固定字段访问。
- 删除不要求立即缩容。
- `for...in` 不强制分配 key 数组。
- 反射和 spread 的 O(n) 成本只在显式使用时发生。
- 未使用字典能力的对象和类不承担字典路径成本。

## 与 JavaScript 的行为差异

| 主题             | JavaScript 普通对象 | Nxts 字典                            |
| ---------------- | ------------------- | ------------------------------------ |
| 缺失读取         | `undefined`         | 保持一致。                           |
| key 规范化       | `ToPropertyKey`     | 数值按规范格式，拒绝对象级隐式转换。 |
| 原型成员         | 默认可能继承        | 纯字典没有继承原型成员。             |
| 原型敏感 key     | 可能触发特殊行为    | 普通数据 key。                       |
| 动态原型和 Proxy | 支持                | 拒绝。                               |
| 枚举顺序         | 规范顺序            | 保持一致。                           |

## 语义测试

| 场景                   | 预期                           |
| ---------------------- | ------------------------------ |
| 缺失动态 key           | 返回 `undefined`。             |
| 写入 `undefined`       | key 仍存在。                   |
| 删除并重新插入         | 枚举位置更新。                 |
| 对象字典视图写入       | 原对象别名观察到结果。         |
| `hasOwn` / `in` 后读取 | 复用探测且行为正确。           |
| 原型敏感 key           | 作为普通数据并产生静态警告。   |
| 自身可枚举成员         | 顺序和实际成员正确。           |
| rest / spread          | 新身份、浅拷贝、从左到右覆盖。 |
