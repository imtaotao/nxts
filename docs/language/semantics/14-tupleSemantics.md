## 目标与边界

本规范定义元组的数组身份、固定长度、索引失败、别名、复制、解构、遍历和枚举等核心可观察行为。固定位置类型、optional/rest 形状和兼容规则见 [`22-tupleTypes.md`](../types/22-tupleTypes.md)，公开方法见 [`2-array.md`](../../stdlib/2-array.md)。

## 身份与长度

元组是具有 JavaScript 数组身份的引用容器：

- 元组属于数组运行时类别；`Array.isArray` 的公开行为由数组标准库定义。
- 赋值、传参和返回默认传递同一引用。
- `===` 与 `!==` 比较身份，不逐元素比较。
- 每次 spread 或 rest 解构语义上创建新的浅拷贝身份。
- 每个实例创建后长度固定，不能增加、删除或补出位置。
- 实际 `0 <= index < length` 的每个位置都存在，不允许空洞。

```ts
const first: [i32, i32] = [1, 2];
const alias = first;
const copy: [i32, i32] = [...first];

first === alias; // true
first === copy; // false
```

优化器只能在身份、别名、写入和逃逸均不可观察时拆分或消除元组对象及复制。

## Optional 与实际存在性

省略 optional 位置与显式存储 `undefined` 保持不同实际长度：

```ts
type Result = [value: string, error?: Error];

const omitted: Result = ["ok"];
const explicit: Result = ["ok", undefined];

omitted.length; // 1
explicit.length; // 2
```

该区别必须反映在 `Object.keys`、遍历和字符串转换中。创建后不能通过写入补出缺失 optional 位置，也不能通过 `delete` 或写入 `length` 移除已存在位置；需要改变存在性时创建新元组。

## 索引与写入失败

动态读取越界返回 `undefined`。动态写入越界抛出 `RangeError`，且元组保持不变。任何写入都不能增加长度或创建空洞。

mutable 元组允许修改已有位置；readonly 只是浅层静态视图，不冻结底层值。其他 mutable 别名的写入仍可由 readonly 视图观察。

rest 元组的运行时长度沿用数组的 `i32` 上限。创建结果超过上限时，在修改任何可观察状态前抛出 `RangeError`。

## 解构与 Spread

普通元组解构按位置读取。解构默认值仅在读取结果为 `undefined` 时惰性求值。空位解构表示跳过读取，不创建元组空洞。

rest 解构创建包含剩余位置的新浅拷贝容器。元组 spread 到数组或另一个元组上下文也创建新浅拷贝；多个 spread 的求值、迭代和失败顺序由 T52 与 T60 定义。

固定 tuple rest 参数可以在不物化参数对象的情况下按普通参数传递；一旦函数体返回、保存、比较或以其他方式观察 `args` 身份，就必须物化真实元组对象。

## 遍历与枚举

元组复用数组遍历模型，不提供额外的索引字面量迭代协议：

- `for...of` 按索引升序遍历当前实际位置。
- 遍历期间修改已有位置会按 JavaScript 顺序影响后续读取。
- 长度不可变，因此迭代不会观察结构增长或缩短。
- `for...in` 与数组相同，属于编译错误。

元组向对象反射暴露的索引集合就是当前实际位置。`Object.keys`、`Object.values` 和 `Object.entries` 的结果类型、身份和 API 行为由[对象标准库](../../stdlib/4-object.md)定义。

## 字符串转换

`join` 与 `toString` 消费当前实际位置序列；具体格式、循环检测和返回行为由[数组标准库](../../stdlib/2-array.md)定义。

元组不能添加自定义属性、覆盖数组方法或修改原型。

## 递归与回收

元组槽位可以引用自身或其他元组。递归能力不增加专用包装、tag、引用计数或运行时深度检查；不可达的自引用与互相引用元组必须由 GC 回收。

## 失败行为

| 场景                             | 结果                          |
| -------------------------------- | ----------------------------- |
| 静态越界读写                     | 编译错误。                    |
| 动态越界读取                     | 返回 `undefined`。            |
| 动态越界写入                     | 抛出 `RangeError`，元组不变。 |
| 写入 `length` 或执行长度修改方法 | 编译错误。                    |
| rest 创建超过最大长度            | 抛出 `RangeError`。           |

内存分配失败由 T46 统一定义。Debug、Release 和优化级别不能改变身份、求值顺序或失败行为。
