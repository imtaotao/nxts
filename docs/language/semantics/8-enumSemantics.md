## 目标与边界

本规范定义枚举声明和枚举值的用户可观察行为。静态类型规则见 [`../types/25-enumTypes.md`](../types/25-enumTypes.md)，标准库转换与遍历见 [`../../stdlib/6-enum.md`](../../stdlib/6-enum.md)。

## 无运行时枚举对象

`enum` 与 `const enum` 都只建立静态命名空间和标量成员常量：

- 声明不生成可观察的运行时对象或模块初始化代码。
- 成员访问不执行属性查找。
- 裸枚举名不能作为值传递、保存或返回。
- 数字枚举不提供反向映射。
- 动态索引、`in`、对象 spread、解构与 `Object.*` 反射不能用于枚举名。
- 运行时表达式 `typeof Enum` 不存在；类型位置的查询仍是静态能力。

```ts
const object = State; // 编译错误
const reverse = State[0]; // 编译错误
Object.keys(State); // 编译错误
```

`const enum` 不比普通 `enum` 多或少任何可观察能力。

## 标量值行为

枚举值沿用底层标量的 JavaScript 行为：

| 操作           | 数字枚举    | 字符串枚举   |
| -------------- | ----------- | ------------ |
| `typeof value` | `"number"`  | `"string"`   |
| 模板插值       | 整数文本    | 原字符串     |
| `toString()`   | 数字文本    | 原字符串     |
| JSON 序列化    | JSON 数字   | JSON 字符串  |
| truthiness     | 按 `i32` 值 | 按字符串值   |
| 对象或字典键   | 数字属性键  | 字符串属性键 |

程序不会自动得到 `"State.Idle"` 一类成员名称。调试器可以使用可选调试元数据显示名称，但该显示不参与语言语义。

## 重复值别名

相同规范值的成员别名在运行时不可区分：

```ts
HttpStatus.Ok === HttpStatus.Success; // true
```

普通枚举值不携带来源成员名。`switch` 中两个重复值别名对应同一分支值，后一个不能形成新的可达状态。

## 有效值不变量

安全 Nxts 程序中的枚举值始终属于声明成员集合。合法来源只有：

- 直接成员常量。
- 已有枚举值的复制、传参、返回和容器读写。
- 成功的受信检查转换。
- T48 定义的外部适配器。

普通底层值、类型断言、未初始化读取、清零内存和未验证数据不能制造枚举值。因此普通复制、比较和分支不重复执行成员有效性检查。

调试或 sanitizer 构建可以增加内部断言，正式优化构建不得增加普通路径成本。

## 性能语义

枚举的普通值操作不得产生：

- 堆分配或包装对象。
- 枚举名称、`TypeId` 或描述符的逐值存储。
- 成员访问哈希或属性查找。
- 普通传参和返回的隐藏枚举参数。
- 普通路径的重复成员验证。

数字枚举目标是与等价 Go 命名整数一致；字符串枚举只承担普通字符串自身的比较、哈希、引用和 GC 成本。

## 语义测试

至少覆盖：

| 场景                       | 预期                                              |
| -------------------------- | ------------------------------------------------- |
| 普通与 `const enum` 声明   | 不生成运行时枚举对象或初始化。                    |
| 数字和字符串成员值         | `typeof`、插值、JSON、truthiness 与底层标量一致。 |
| 重复值别名严格比较         | 结果为 `true`，无来源名称差异。                   |
| 动态索引、反向映射和反射   | 静态拒绝。                                        |
| 普通复制、调用、比较和分支 | 不执行成员验证或分配。                            |
| 未验证外部值               | 不能直接成为枚举。                                |
