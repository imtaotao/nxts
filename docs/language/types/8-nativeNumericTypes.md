## 数值类型清单

```text
number

i8 i16 i32 i64
u8 u16 u32 u64

f32 f64

usize isize
```

`number` 保持 JavaScript Number 语义。其他类型是 Nxts 原生能力，不冒充 JavaScript `number`。

每个名称都是独立语义类型。即使两个类型具有相同机器表示，它们也不相等，不存在由表示相同自动产生的子类型或隐式兼容。

## `number`

`number` 值域包括：

- `NaN`。
- `Infinity` 与 `-Infinity`。
- `-0`。
- JavaScript 安全整数和其他 IEEE 754 binary64 值。

`number` 与 `f64` 是不同类型，不互相隐式兼容。需要改变语义类型身份时使用显式数值转换。

支持的 `number` 二元算术、关系比较和严格相等要求两侧都是 `number`：

| 运算                    | 结果类型  |
| ----------------------- | --------- |
| `+`、`-`、`*`、`/`、`%` | `number`  |
| `<`、`<=`、`>`、`>=`    | `boolean` |
| `===`、`!==`            | `boolean` |

不支持：

- `==`、`!=`。
- `number` 位运算和移位。
- 字符串、boolean 或对象到 `number` 的隐式 `ToNumber`。

`Number(value)`、`Number.isNaN`、`Number.isFinite` 和 `Math` 函数属于 T49 标准库边界。

## 数字字面量推导

有上下文类型时，数字字面量优先按上下文检查：

```ts
const jsValue: number = 1;
const nativeInt: i32 = 1;
const nativeFloat: f64 = 1.5;
```

字面量必须满足目标类型的范围、精度和特殊值规则。

无上下文时：

| 字面量形态                     | 默认基础类型 |
| ------------------------------ | ------------ |
| 普通整数字面量                 | `i32`        |
| 普通浮点字面量                 | `f64`        |
| `NaN`、`Infinity`、`-Infinity` | `number`     |
| `-0`                           | `number`     |
| 无法安全选择原生类型           | `number`     |

```ts
let count = 1; // i32
let ratio = 1.5; // f64
let value = NaN; // number
```

`const` 按 T05 保留字面量类型，widening 后回到本节确定的基础类型：

```ts
const count = 1; // i32 基础上的字面量 1
const negativeZero = -0; // number 基础上的字面量 0，保留负零事实
```

已经确定类型的变量不能借助上下文改变类型：

```ts
let native = 1; // i32
native = 1.5; // 编译错误
```

checker 不得为了性能把已经推导为 `number` 的值改写为其他数值类型。

## 固定宽度整数

| 宽度 | 有符号范围             | 无符号范围         |
| ---: | ---------------------- | ------------------ |
|    8 | `i8`: `-2^7..2^7-1`    | `u8`: `0..2^8-1`   |
|   16 | `i16`: `-2^15..2^15-1` | `u16`: `0..2^16-1` |
|   32 | `i32`: `-2^31..2^31-1` | `u32`: `0..2^32-1` |
|   64 | `i64`: `-2^63..2^63-1` | `u64`: `0..2^64-1` |

不同宽度和符号性的整数不隐式兼容。

### 整数操作数类型

已经确定类型的操作数必须相同：

| 运算                    | 操作数与结果                       |
| ----------------------- | ---------------------------------- |
| `+`、`-`、`*`、`/`、`%` | 两侧同一整数类型，结果保持该类型。 |
| `<`、`<=`、`>`、`>=`    | 两侧同一整数类型，结果 `boolean`。 |
| `===`、`!==`            | 两侧同一整数类型，结果 `boolean`。 |
| 一元 `-`                | 只接受有符号整数，结果保持类型。   |

未定型整数字面量可以采用赋值、参数或另一操作数提供的上下文，且必须在范围内：

```ts
const increment = (count: u64) => {
  const next = count + 1; // u64
  const invalid = count + -1; // 编译错误
};

const consumeU64 = (value: u64) => {};
consumeU64(1); // 字面量直接采用 u64 上下文
```

具体数值变量不能借助上下文改变类型：

```ts
const mixIntegers = (small: i32, large: i64, unsigned: u32) => {
  small + large; // 编译错误
  small + unsigned; // 编译错误
};
```

与 `number`、`f32`、`f64` 的运算也要求先显式转换。

### 整数位运算

当前版本不支持 `&`、`|`、`^`、`~`、`<<`、`>>`、`>>>`。原生整数位运算可以未来扩展，但必须先由 T50 确定移位量、符号扩展、越界和结果类型。

## 原生浮点

| 类型  | 语义精度                                      |
| ----- | --------------------------------------------- |
| `f32` | IEEE 754 binary32，每个结果按 binary32 舍入。 |
| `f64` | IEEE 754 binary64，每个结果按 binary64 舍入。 |

两种类型都包含 `NaN`、正负无穷和 `-0`。

已经确定类型的浮点操作数必须相同：

| 运算                    | 操作数与结果                         |
| ----------------------- | ------------------------------------ |
| `+`、`-`、`*`、`/`、`%` | 两侧同一原生浮点类型，结果保持类型。 |
| `<`、`<=`、`>`、`>=`    | 两侧同一类型，结果 `boolean`。       |
| `===`、`!==`            | 两侧同一类型，结果 `boolean`。       |
| 一元 `-`                | 保持 `f32` 或 `f64`。                |

`f32`、`f64` 和 `number` 之间不隐式扩宽、收窄或改变语义身份。

字面量和 `NaN`、`Infinity`、`-Infinity`、`-0` 可以采用明确的 `f32` 或 `f64` 上下文，不产生运行时转换：

```ts
const calculateF32 = (value: f32) => {
  const result = value + 1.5; // f32
};

const consumeF64 = (value: f64) => {};
consumeF64(1.5); // 直接生成 f64 字面量
```

### 浮点字面量检查

有限字面量按目标类型直接解析和舍入：

| 结果                     | 静态诊断   |
| ------------------------ | ---------- |
| 有限正规值               | 接受。     |
| 非零次正规值             | 接受。     |
| 有限非零字面量溢出为无穷 | 编译错误。 |
| 有限非零字面量下溢为零   | 编译错误。 |

需要无穷或零时必须显式写 `Infinity`、`-Infinity`、`0` 或 `-0`。

普通浮点运算产生的溢出、下溢和特殊值不属于字面量错误。

## 平台整数

`usize` 和 `isize` 的宽度等于目标指针宽度 `N`：

| 类型    | 范围                  |
| ------- | --------------------- |
| `usize` | `0..2^N-1`            |
| `isize` | `-2^(N-1)..2^(N-1)-1` |

二者不是同宽固定整数的别名。目标平台只决定宽度、范围和 ABI 表示，不改变类型身份。

### 使用领域

| 场景                         | 类型                |
| ---------------------------- | ------------------- |
| 内存分配大小、对象大小和对齐 | `usize`             |
| 原始内存索引和地址计算       | `usize`             |
| 可能为负的指针偏移或地址差   | `isize`             |
| 平台宽度 FFI 参数            | 按外部 ABI 显式选择 |

普通数组、字符串和同类内存内集合使用 `i32` 长度与索引，最大值为 `2^31-1`。平台整数作为普通索引前必须显式转换为 `i32`。

规模领域必须明确：

| 领域                           | 类型边界                            |
| ------------------------------ | ----------------------------------- |
| 普通数组、字符串和同类集合     | `i32`                               |
| 文件大小、流偏移和数据库大计数 | `i64` 或 `u64`                      |
| 内存大小、对齐和地址偏移       | `usize` 或 `isize`                  |
| 网络、文件格式和持久化字段     | 协议规定的固定宽度整数              |
| 超大连续缓冲区                 | 专用原生缓冲区，长度 `usize`        |
| 超大逻辑序列                   | 分段或流式结构，长度 `i64` 或 `u64` |

`usize` 和 `isize` 不能用于跨目标稳定文件格式、网络协议或持久化布局。

### 平台整数操作数类型

平台整数复用整数运算类别，但两侧必须同为 `usize` 或同为 `isize`。未定型字面量可以采用对应上下文并执行目标范围检查。

`usize` 与 `isize`、平台整数与固定宽度整数之间不隐式转换。`usize` 不支持一元负号，`isize` 支持。

## 显式转换边界

不同数值类型之间不存在隐式转换。数字字面量采用上下文类型不属于转换；已经确定类型的值必须调用标准库显式入口。

数值转换分为：

| 类别                          | 静态结果         |
| ----------------------------- | ---------------- |
| 普通转换 `toTarget(value)`    | `Target`         |
| 精确转换 `tryToTarget(value)` | `Target \| null` |

具体 API、舍入、截断、饱和和失败行为由[数值标准库](../../stdlib/5-numeric.md)定义。

`number` 与 `f64` 的显式转换只改变语义类型身份，不要求运行时指令。其他转换只生成目标表示确实需要的原生操作，不装箱或堆分配。

数值转换不能使用 `as`。

## Checker 职责

- 建立所有数值类型的独立身份。
- 按上下文检查字面量范围、精度和特殊值。
- 执行默认数字字面量推导。
- 要求具体操作数类型相同。
- 拒绝隐式数值转换、动态 `ToNumber`、宽松相等和当前位运算。
- 保留平台整数的目标相关身份和稳定布局限制。
- 识别绑定后的标准库 intrinsic 身份，不按函数名称猜测转换。

Checked HIR 必须保留数值语义类型、宽度、符号性、精度和操作类别。

## 与 TypeScript / JavaScript 的类型差异

| 主题           | TypeScript / JavaScript     | Nxts                             |
| -------------- | --------------------------- | -------------------------------- |
| 普通数字字面量 | 默认 `number`               | 整数默认 `i32`，浮点默认 `f64`。 |
| 原生整数和浮点 | 不存在独立静态类型          | 提供固定宽度与平台类型。         |
| 数值混合运算   | JavaScript 只有 Number 世界 | 不同类型必须显式转换。           |
| 宽松相等       | JavaScript 支持             | 不支持。                         |
| 位运算         | `number` 隐式转 32 位       | 当前全部拒绝。                   |
| `number`       | IEEE 754 binary64           | 保持 JavaScript 语义。           |

原生类型是 Nxts 扩展；其余接受范围保持 TypeScript strict 的静态子集。

## 诊断与类型测试

| 场景                           | 结果                     |
| ------------------------------ | ------------------------ |
| `let count = 1`                | `i32`。                  |
| `let ratio = 1.5`              | `f64`。                  |
| `let value = NaN`              | `number`。               |
| `numberValue + otherNumber`    | `number`。               |
| `i32Value + i64Value`          | 编译错误。               |
| `u64Value + 1`                 | `u64`。                  |
| `u64Value + -1`                | 编译错误。               |
| `f32Value + 1.5`               | `f32`。                  |
| `f32Value + f64Value`          | 编译错误。               |
| `const value: f32 = 1e100`     | 编译错误。               |
| `numberValue << 1`             | 编译错误。               |
| `usizeValue + u64Value`        | 编译错误，即使目标同宽。 |
| 普通数组索引使用 `usize`       | 未显式转换时编译错误。   |
| 使用平台整数声明跨目标稳定布局 | 编译错误。               |

## 依赖关系

- T04、T05 和 T20 定义公共类型、推导与字面量身份。
- T13 定义数值 key 和字符串转换格式。
- T14、T21 和 T24 定义 `Target | null` 与收窄。
- T23、T45 和 T47 定义转换结果表示和跨模块 ABI。
- T34 定义普通集合 `i32` 索引。
- T48 定义 FFI 映射。
- T49 定义数值标准库。
- T50 定义表达式入口和未来位运算。
