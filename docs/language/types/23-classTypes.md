## 核心类型模型

类同时建立类型空间和值空间中的绑定：

| 位置       | 类名称的含义                                              |
| ---------- | --------------------------------------------------------- |
| 类型位置   | 当前类的实例类型。                                        |
| 值位置     | 当前类的构造器与静态侧值。                                |
| `typeof C` | 类 `C` 的构造签名、静态成员和运行时类身份组成的静态类型。 |

```ts
class User {
  static count = 0;
  name: string;

  constructor(name: string) {
    this.name = name;
  }
}

let user: User = new User("Ada");
let constructorValue: typeof User = User;
```

类具有以下静态不变量：

| 不变量       | 要求                                              |
| ------------ | ------------------------------------------------- |
| 名义实例身份 | 无关类即使成员相同也不兼容。                      |
| 固定实例形状 | 固定字段和成员类别在编译期确定。                  |
| 单继承       | 每个类最多有一个运行时基类。                      |
| 继承子类型   | 只有静态 `extends` 建立派生类到基类的类子类型。   |
| 接口独立     | `implements` 不增加运行时基类或改变类身份。       |
| TS 静态子集  | 接受的源码保持 TypeScript strict 可解析和可检查。 |

## 声明形式与支持范围

支持模块级和局部类声明、命名与匿名类表达式：

```ts
class Service {}

function makeService(prefix: string) {
  return class LocalService {
    name = `${prefix}:service`;
  };
}
```

| 类别     | 支持能力                                                       |
| -------- | -------------------------------------------------------------- |
| 字段     | 实例与静态字段、可选字段、`readonly`、参数属性和箭头函数字段。 |
| 方法     | 实例与静态方法、访问器、重载、覆盖以及未来异步和生成器方法。   |
| 继承     | 静态已知的单继承、`super`、构造器转发和接口 `implements`。     |
| 初始化   | 字段初始化器、构造器、静态字段初始化器和静态初始化块。         |
| 动态类值 | 局部类、类表达式、类值传递、类身份比较和类型安全动态构造。     |
| 动态字段 | T30 显式索引签名承载的实例动态字段和动态计算成员名。           |

以下形式编译错误：

| 不支持能力                           | 原因或替代                                     |
| ------------------------------------ | ---------------------------------------------- |
| `abstract class` 和抽象成员          | 使用接口与普通基类。                           |
| JavaScript `#private`                | 当前使用 TypeScript `private`。                |
| 装饰器                               | 不引入隐藏改写和初始化协议。                   |
| 多继承、mixin 和运行时计算 `extends` | 无法静态确定唯一布局和方法槽位。               |
| `extends null`                       | 不支持无原型类模型。                           |
| `final`、`sealed` 和 `override`      | 不增加额外关键字；编译器自动证明封闭性和覆盖。 |
| 原型、属性描述符或构造器对象动态修改 | 类结构固定。                                   |
| 应用源码中的 ambient `declare class` | 不能伪造原生布局、GC 和 ABI。                  |

parser 可以识别这些语法并产生针对性诊断，但不能为无效输入建立可进入 Checked HIR 的类定义。

## 类身份与兼容

每个类声明具有独立名义身份：

```ts
class Left {
  value: i32;
}

class Right {
  value: i32;
}

const value: Left = new Right(); // 编译错误
```

静态 `extends` 建立派生类到基类的单向兼容：

```ts
class Animal {}
class Dog extends Animal {}

const dog = new Dog();
const animal: Animal = dog;

dog === animal; // true
```

该转换必须是零复制、零裁剪和零对象地址调整。类身份由 T55 规范化的模块身份与声明身份共同确定；同一声明的导入和转导出保持身份，不同模块实例或不同依赖版本中的同名声明不是同一类。

局部类和类表达式每次求值产生的运行时身份不同，但其静态实例类型仍绑定对应类求值表达式的类型事实。不能仅因布局模板相同而把无关类视为兼容。

## 实例侧与静态侧

实例字段和实例方法只属于实例侧，静态字段和静态方法只属于静态侧。`implements` 只检查实例侧。

构造器值采用名义类结果和严格构造签名：

```ts
function create(Ctor: new () => Animal): Animal {
  return new Ctor();
}

create(Dog);
```

`typeof Derived` 只有在以下条件同时满足时才能赋给 `typeof Base`：

- `Derived extends Base`。
- 派生构造签名能安全用于目标调用位置。
- 目标可观察静态成员满足静态侧兼容要求。

无关类不能仅凭静态成员和构造参数结构相同获得兼容。纯构造签名接口可以接收构造参数兼容且结果属于目标基类的类值。

## 字段声明与推导

所有固定实例字段必须在类体中声明。构造器赋值不能隐式创建字段：

```ts
class Point {
  x: i32;
  y: i32;

  constructor(x: i32, y: i32) {
    this.x = x;
    this.y = y;
  }
}
```

没有显式索引签名的类不能通过动态索引增加实例字段。T30 类索引签名可以建立独立动态字段区域，但不能改变固定字段类型和身份。

| 字段形式                  | 推导结果                           |
| ------------------------- | ---------------------------------- |
| 显式注解和初始化器        | 注解提供上下文，初始化器必须兼容。 |
| mutable 字面量初始化器    | 按普通 mutable 位置 widening。     |
| `readonly` 字面量初始化器 | 可以保留 T20 允许的字面量精度。    |
| 无注解但有可推导初始化器  | 使用初始化器推导。                 |
| 无注解且无初始化器        | 编译错误；可选字段除外。           |
| 无上下文空数组或空容器    | 无法确定元素或成员类型时编译错误。 |

父类字段在派生类重声明时提供上下文，不能因窄字面量初始化器缩小可写槽位：

```ts
class Base {
  value: string | i32 = 0;
}

class Valid extends Base {
  value = ""; // 仍为 string | i32
}

class Invalid extends Base {
  value: string = ""; // 编译错误
}
```

字段类型推导只产生静态信息，不增加运行时 tag、装箱或动态类型判断。

## 确定赋值

必需实例字段必须由字段初始化器、参数属性或构造器所有正常完成路径赋值。Nxts 不支持 definite assignment `!`：

```ts
class Config {
  path: string;

  constructor(path: string) {
    this.path = path;
  }
}
```

checker 必须：

- 禁止在字段赋值前读取。
- 禁止在必需字段完成前枚举或泄漏实例。
- 按类层级和源码初始化顺序更新字段状态。
- 验证所有正常完成路径已经初始化全部必需字段。
- 不因底层内存已清零而放宽确定赋值。

固定字段不需要为构造期间的临时未初始化状态保留长期运行时 tag。

## 可选字段

`field?: T` 的读取类型为 `T | undefined`。属性存在与缺失的行为由[类语义](../semantics/7-classSemantics.md)定义。

规则如下：

- 写入兼容 `T` 或允许的 `undefined` 值合法。
- 可写可选字段允许 `delete`。
- `readonly` 可选字段不能删除。
- 派生类不能改变继承字段的可选性。
- 类型系统必须区分可选字段与必需的 `T | undefined` 字段。

## `readonly` 字段

实例 `readonly` 字段只能在以下位置写入：

| 位置                      | 是否允许 |
| ------------------------- | -------- |
| 字段声明初始化器          | 允许。   |
| `readonly` 参数属性初始化 | 允许。   |
| 声明该字段的类构造器      | 允许。   |
| 普通方法或派生类构造器    | 拒绝。   |
| 构造完成后的外部写入      | 拒绝。   |

声明类构造器可以多次写入自己的 `readonly` 字段；正常完成时最后一次写入成为最终值。所有正常路径仍必须完成确定赋值。

静态 `readonly` 字段必须直接具有声明初始化器。静态块、派生类和普通静态方法不能补写或修改。

`readonly` 只限制静态写权限，不建立冻结、复制或防御性包装。

## 字段重声明与成员类别

派生类重声明继承字段时必须保持：

- 规范字段类型一致。
- 可选性、`readonly` 和可见性一致。
- 实例或静态类别一致。
- 固定字段种类不变。

没有新初始化器或其他语义的冗余重声明编译错误。

普通数据字段不能改为方法或访问器。函数值字段和方法具有不同的接收者、枚举和实例身份语义，默认不能互换。

允许派生类箭头函数字段覆盖基类普通方法，但签名必须兼容：

```ts
class BaseHandler {
  handle(value: string): void {}
}

class BoundHandler extends BaseHandler {
  handle = (value: string): void => {};
}
```

反方向不允许：基类函数值字段不能由派生类普通方法覆盖。普通数据字段、访问器和方法之间的其他跨类别覆盖均编译错误。

## 构造签名

构造器只能通过 `new` 调用：

```ts
class Item {}

new Item(); // 合法
Item(); // 编译错误
```

构造器支持 public、protected 和 private 可见性。构造器重载复用 T32–T33 的有序签名、参数数量和严格兼容规则，同一类只能具有一个实现体。

没有显式构造器时：

| 类别   | 隐式签名                         |
| ------ | -------------------------------- |
| 基类   | 提供无参数构造器。               |
| 派生类 | 接受并类型化转发基类构造器参数。 |

派生构造器每条正常完成路径必须恰好调用一次 `super(...)`。调用前不能使用 `this`。

构造器不能：

- 声明为 async 或生成器。
- 声明显式返回类型。
- 返回替代对象。
- 使用带值 `return value`。

裸 `return;` 表示正常结束构造。

## `new.target` 类型

`new.target` 仅允许在类构造器主体及其词法箭头函数中使用。静态类型为当前类的构造器类型，运行时值行为由[类语义](../semantics/7-classSemantics.md)定义。

类字段初始化器、普通方法、访问器和静态初始化块中的 `new.target` 编译错误。

## 构造安全

checker 对每个构造阶段跟踪已初始化字段。构造器调用的方法及其可能派生覆盖必须满足：

- 只读取当前阶段已经保证初始化的字段。
- 不通过派生覆盖读取尚未开始初始化的派生字段。
- 不把未完成的 `this` 存入外部对象、返回、异步捕获或传给无法证明安全的调用。
- 跨方法和跨模块调用只使用编译器生成的构造安全摘要。

无法证明安全时编译错误，并报告构造调用链和最早可能读取的未初始化字段。该证明不能为实例增加初始化位图或字段读取检查。

## 继承图

`extends` 目标必须解析为静态已知、可继承的类。类继承图必须无环；直接、间接或跨模块循环继承均编译错误。

继承深度和成员数量不设置较小语言级上限。checker 使用版本确定的工作预算和规范 `TypeId` 缓存限制恶意输入；超限产生确定性编译错误，不能静默改变兼容、覆盖或派发规则。

普通内建类型默认不可继承。白名单和 `Error` 派生能力由[类内建能力](../../stdlib/3-classBuiltins.md)定义。

## 实例方法与覆盖

编译器自动识别覆盖，不要求也不接受 `override`：

| 约束     | 要求                                                              |
| -------- | ----------------------------------------------------------------- |
| 参数     | 使用 T32 严格逆变和参数数量规则，不采用 TypeScript 方法双变例外。 |
| 返回值   | 协变，且不要求隐藏表示转换、分配或运行时检查。                    |
| 可见性   | 不能缩小继承成员可见性。                                          |
| 成员类别 | 普通方法覆盖普通方法；访问器按访问器规则覆盖。                    |
| 重载     | 公开重载集合和唯一实现满足 T33。                                  |

private 方法不参与覆盖。`super.method(...)` 的目标静态确定。

方法提取、接收者保留和箭头绑定沿用 T32：提取普通方法不会自动绑定实例，缺少接收者的裸调用编译错误。

## 访问器

类支持实例和静态 getter / setter，以及 public、protected、private 可见性：

```ts
class Size {
  private raw: i32 = 0;

  get value(): i32 {
    return this.raw;
  }

  set value(next: i32) {
    this.raw = next;
  }
}
```

- getter 返回类型与 setter 参数类型必须规范一致。
- getter-only 成员为只读。
- setter-only 成员编译错误。
- backing storage 必须显式声明。
- 字段、方法和访问器不能通过同名声明任意互换。
- 动态属性描述符和运行时 getter 安装不属于类能力。

## 箭头函数字段

箭头函数字段是函数值字段，具有自动绑定接收者的类型：

```ts
class Button {
  readonly click = (): void => {
    this.handle();
  };

  private handle(): void {}
}
```

接口函数值属性可以由兼容箭头字段满足；普通接口方法要求方法类别和接收者契约，二者不自动互换。

箭头函数字段的身份、捕获和表示由类语义、T58 与类运行时规范定义。

## 异步与生成器方法

普通实例方法、静态方法和箭头函数字段保留 async、生成器和异步生成器语法入口。只有 T59–T60 定稿并实现后，这些形式才能进入有效程序。

构造器、getter、setter 和静态初始化块不能声明为 async 或生成器。覆盖方法必须满足对应 Promise、Iterator 或 AsyncIterator 签名。

## 访问控制

| 修饰符      | 静态访问范围                         |
| ----------- | ------------------------------------ |
| `public`    | 默认；所有可见位置。                 |
| `protected` | 声明类及其派生类中的合法接收者位置。 |
| `private`   | 仅声明类内部。                       |

参数属性支持相同访问修饰符和 `readonly`。

TypeScript `private` 只提供编译期访问控制：

- private 方法不参与派生覆盖。
- private / protected 成员不能满足接口 public 成员。
- 动态索引、反射和类型断言不能绕过访问控制。
- 不宣称 private 字段提供运行时隔离。

## 接口实现

`implements` 是可选编译期检查，不改变类布局、方法表或运行时身份：

```ts
interface Named {
  name: string;
}

class User implements Named {
  name = "user";
}
```

一个类可以实现多个接口。继承得到的 public 字段和方法可以满足接口；private 和 protected 成员不能满足 public 契约。

省略 `implements` 时，只要类实例在转换点结构化满足接口，仍可形成接口视图。接口只存在于类型空间，不能构造，也不能作为 `instanceof` 右操作数。

## 静态字段类型

静态字段属于静态侧。必需静态字段必须由声明初始化器或后续静态初始化块的所有正常路径赋值。

在赋值前读取必需静态字段，或把仍有必需静态字段未初始化的类值泄漏给无法证明安全的代码，编译错误。Nxts 不支持静态 definite assignment `!`。

静态可选字段读取类型为 `T | undefined`。可写可选静态字段允许 `delete`。静态继承的可观察读写行为由[类语义](../semantics/7-classSemantics.md)定义。

## 计算成员名与动态字段

可在编译期归一为字符串或数值字面量的计算成员名按固定成员处理：

```ts
const key = "status";

class Task {
  [key] = "ready";
}
```

规范化后重复的固定成员键编译错误。

宽字符串计算实例成员名只允许类具有兼容 T30 显式索引签名。没有索引签名的类不能因动态成员名获得隐式字典能力。TypeScript 无法表达静态侧索引契约时，宽动态静态成员名编译错误。

## `instanceof` 类型规则

`instanceof` 右操作数必须静态确定为类构造器值：

```ts
function matches(value: Animal, Ctor: typeof Animal): boolean {
  return value instanceof Ctor;
}
```

普通函数、普通对象、接口、`unknown` 构造器值或无法证明为类构造器的联合不能作为右操作数。接口不能作为 `instanceof` 目标。

判断成功时按 T24 收窄为右侧构造器代表的实例类型；有限构造器联合的精确收窄由 T24 定义。

## 泛型类边界

保留 TypeScript 泛型类语法：

```ts
class Box<T> {
  value: T;

  constructor(value: T) {
    this.value = value;
  }
}
```

实例字段和实例方法可以使用类类型参数。静态成员不能引用类类型参数，因为所有 `Box<T>` 共享同一个运行时类身份和静态状态。

不同闭合类型实参形成不同静态实例类型，但 `instanceof Box` 只检查类身份，不检查类型参数。类型参数不提供运行时反射。

具体约束、推导、方差、代码共享和代码体积策略由 T37–T38 定义。

## 可信声明边界

应用源码中的 `declare` 字段、无实现方法和 `declare class` 编译错误。无实现签名只允许作为同一方法或构造器实现前相邻的 T33 重载签名。

工具链可信的标准库、runtime 和宿主声明模块可以包含 ambient 类声明，但必须：

- 绑定真实编译器或 runtime 类身份。
- 由 T45–T47 校验布局、GC 描述、方法入口和 ABI。
- 不生成普通用户类代码。
- 不能通过声明合并或模块扩充改变已发布类结构。

标准库与 runtime 的内部调用可以使用编译器私有 ABI，但必须通过独立适配层与类类型模型解耦。未来公开 FFI 时不能要求重写 checker 的类身份、构造签名或成员模型。

## 声明合并与扩展

不支持：

- 重复类声明。
- class / interface 同名合并。
- namespace 与类合并。
- 模块扩充为类追加成员。
- 通过原型赋值追加方法。

需要扩展行为时使用派生类、接口、组合对象或显式注册表。

## Checker 职责

checker 必须：

- 建立类声明的名义实例身份和静态侧类型。
- 检查字段推导、确定赋值、可选性和 `readonly`。
- 建立继承图并拒绝循环。
- 检查字段重声明、方法覆盖、访问器和成员类别。
- 检查构造签名、`super()`、`new.target` 位置和构造安全。
- 检查访问控制、接口实现、泛型边界和动态成员名。
- 生成覆盖、构造安全和副作用所需的可信摘要。

类语义、覆盖解析和构造安全必须在 Checked HIR 前确定，不能推迟给后端猜测。

## 与 TypeScript 的类型差异

| 主题                   | TypeScript               | Nxts                               |
| ---------------------- | ------------------------ | ---------------------------------- |
| 类实例兼容             | 多数类结构兼容           | 类始终采用名义身份。               |
| 方法参数方差           | 方法保留双变例外         | 严格逆变。                         |
| `override`             | 可选或由配置要求         | 不支持关键字，自动识别。           |
| 抽象类                 | 支持                     | 拒绝；使用接口和普通基类。         |
| `#private`             | 支持                     | 当前拒绝。                         |
| `private`              | 编译期限制               | 保持编译期限制，不宣称运行时隐藏。 |
| 动态 `extends` / mixin | 可描述部分模式           | 拒绝。                             |
| 构造器返回对象         | 类型系统允许部分 JS 行为 | 拒绝带值返回。                     |
| 字段类型重声明         | 允许部分 narrowing       | 可写固定槽位保持规范类型。         |
| 声明合并与 ambient 类  | 支持                     | 应用源码拒绝；仅可信工具链声明。   |

这些差异缩小 TypeScript strict 的接受范围，不允许 Nxts 接受 TypeScript 无法验证的额外类源码。

## 诊断与类型测试

| 场景                                 | 预期                       |
| ------------------------------------ | -------------------------- |
| 无关同结构类赋值                     | 编译错误。                 |
| 派生类赋给基类                       | 零复制合法并保持身份。     |
| 类赋给满足的接口                     | 形成共享 witness 视图。    |
| 实例名与 `typeof` 类名               | 分别解析为实例侧和静态侧。 |
| 通过兼容构造签名传递派生类           | 合法。                     |
| 某条正常路径遗漏必需字段             | 编译错误。                 |
| 构造器调用可能读取未初始化字段的方法 | 编译错误并报告调用链。     |
| 无初始化器可选字段                   | 类型为 `T \| undefined`。  |
| 显式缩窄可写继承字段                 | 编译错误。                 |
| 普通方法覆盖与 `super.method()`      | 签名合法时接受。           |
| 派生箭头字段覆盖普通方法             | 签名兼容时合法。           |
| 派生普通方法覆盖基类函数值字段       | 编译错误。                 |
| getter-only 写入                     | 编译错误。                 |
| setter-only 声明                     | 编译错误。                 |
| private / protected 非法访问         | 编译错误。                 |
| `implements` 只依赖 private 成员     | 不能满足 public 接口。     |
| 常量计算成员名                       | 固定成员。                 |
| 宽动态成员名无索引签名               | 编译错误。                 |
| `instanceof` 使用普通函数或接口      | 编译错误。                 |
| 抽象类、`#private`、装饰器、原型修改 | 编译错误。                 |
