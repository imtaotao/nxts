## 核心原则

字典表示运行时确定的键值集合；普通对象表示编译期确定的字段集合。

| 原则     | 约束                                                            |
| -------- | --------------------------------------------------------------- |
| 源码统一 | 使用相同属性、索引和删除语法，不书写表示转换。                  |
| 表示分流 | 宽动态 key 直接形成字典；固定对象进入字典位置时形成零复制视图。 |
| 身份不变 | 字典视图保留底层对象身份和别名可见性。                          |
| 缺失安全 | 未证明存在的读取类型为 `V \| undefined`。                       |
| 局部付费 | 未使用字典能力的对象和类保持固定字段路径。                      |
| 性能目标 | 原生字典最终以 Go map 为目标。                                  |

原生字典和对象字典视图是内部表示差异，不形成两套用户类型语法或要求用户复制对象。

## 支持的索引签名

```ts
type StringTable = {
  [key: string]: string;
};

type NumberTable = {
  [key: number]: i32;
};

type ReadonlyTable = {
  readonly [key: string]: string;
};
```

| 形式                   | 结论                                                 |
| ---------------------- | ---------------------------------------------------- |
| `[key: string]: V`     | 支持字符串键和按 JavaScript 规则规范化的数值键。     |
| `[key: number]: V`     | 支持数值键和可证明为规范数值属性名的字符串字面量键。 |
| `readonly [key: K]: V` | 支持读取、存在检查和枚举，禁止写入和删除。           |
| `[key: symbol]: V`     | 当前不支持。                                         |
| `[key: string]?: V`    | 不支持；缺失由读取规则表达。                         |

索引参数名不参与类型身份。参数类型必须规范化为宽 `string` 或 `number`，不能用 `any`、`unknown`、对象或用户转换进入索引签名。

## 类型身份

字典规范类型包含：

```text
DictionaryType {
  keyDomain
  valueType
  access
  fixedMembers
}
```

| 参与身份                       | 不参与身份                |
| ------------------------------ | ------------------------- |
| 键域、值类型和写权限           | 索引参数名称              |
| 固定成员键、类型、可选性和权限 | 声明顺序                  |
| 字符串与数值签名组合           | 哈希容量、salt 和扩容状态 |

字典与 `Map<K, V>` 是不同类型，不隐式转换。需要独立数值身份、对象 key 或不执行字符串规范化的 key 时使用 `Map`。

## 字符串与数值签名重叠

同一类型可以声明字符串和数值索引签名：

```ts
interface Values {
  [key: string]: Animal;
  [key: number]: Dog;
}
```

因为 `values[1]` 与 `values["1"]` 指向同一条目：

| 权限组合                 | 兼容要求                                     |
| ------------------------ | -------------------------------------------- |
| 两者均可写               | 值类型必须相同。                             |
| 两者均只读               | 数值签名值类型可以是字符串签名值类型子类型。 |
| 任一方向可能破坏另一签名 | 值类型必须相同。                             |

数值名称固定成员同时满足两个签名；其他命名成员至少满足字符串签名。checker 不插入运行时检查修补不安全声明。

## 固定成员与索引签名

索引签名可以与固定成员组合：

```ts
interface Config {
  mode: string;
  [key: string]: string;
}
```

固定成员存在时，其存储值类型必须能读取为对应索引值类型；可选成员的缺失 `undefined` 不参与存储值兼容。

```ts
config.mode; // string
config['mode']; // string
config[key]; // string | undefined
```

静态已知 key 优先使用固定成员类型与权限。宽动态写入可能与较窄固定成员或类方法重叠时，checker 必须记录别名副作用，不能继续假定成员保持原事实。失效算法由 T58 定义。

## 字面量推导

| key 类型                   | 推导结果                       |
| -------------------------- | ------------------------------ |
| 单个字符串或数值字面量     | 固定属性。                     |
| 有限字符串或数值字面量联合 | 精确对象联合或固定存在位布局。 |
| 宽 `string`                | 字符串字典。                   |
| 宽 `number`                | 数值索引字典。                 |
| `symbol`                   | 编译错误。                     |

宽字符串 key 使全部字符串条目进入同一字典值类型：

```ts
const createStringDictionary = (key: string) => {
  const mixed = {
    [key]: 'value',
    count: 1,
  };
  // { [key: string]: string | number }
};
```

宽数值 key 只覆盖数值属性名，非数值字符串成员保留固定成员：

```ts
const createNumberDictionary = (index: number) => {
  const values = {
    [index]: 'value',
    count: 1,
  };
  // { [key: number]: string; count: number }
};
```

值类型使用 T04 公共上界和 T21 规范联合，不能以 `any` 或 `unknown` 兜底。字典类型建立后不会因后续写入扩大。

空对象按上下文分流：

```ts
const exact = {}; // 精确空对象
const dict: { [key: string]: i32 } = {}; // 原生空字典

const raw = {};
const view: { [key: string]: i32 } = raw; // 零复制视图
```

无上下文 `{}` 不推导为字典。

同一字面量中可静态确定的重复规范 key 编译错误；`1` 与 `"1"` 是同一个 key。宽动态冲突由字典语义定义。

## 读取类型与存在性收窄

动态索引只保证已存在条目的值属于 `V`：

```ts
const dict: { [key: string]: i32 } = {};

dict['missing']; // i32 | undefined
```

| 场景                   | 结果类型                   |
| ---------------------- | -------------------------- |
| 必需固定成员           | 成员类型 `T`。             |
| 可选固定成员           | `T \| undefined`。         |
| 未证明存在的动态 key   | `V \| undefined`。         |
| 稳定 key 已证明存在    | `V`。                      |
| `V` 本身含 `undefined` | 保留该成员，存在状态独立。 |

```ts
if (Object.hasOwn(dict, key)) {
  dict[key]; // V
}

if (key in dict) {
  dict[key]; // V
}
```

存在检查与读取必须形成关联事实，使后续阶段可以复用哈希探测。对象写入、key 重新赋值、删除调用或别名副作用会使事实失效。

## 写入与删除检查

可写字典接受可赋给 `V` 的值。已知固定 key 仍使用成员自身类型和权限：

```ts
config.mode = 'fast'; // 合法
config.mode = 1; // 编译错误
```

写入稳定动态 key 后可以记录该 key 存在。写入 `undefined` 在 `V` 允许时不等于删除。

| 目标             | 静态结论             |
| ---------------- | -------------------- |
| 必需固定成员     | 删除编译错误。       |
| 可写可选固定成员 | 删除允许。           |
| 只读固定成员     | 写入和删除编译错误。 |
| 可写动态字典 key | 写入和删除允许。     |
| 只读字典         | 写入和删除编译错误。 |

宽 key 写入或删除可能命中固定字段或类方法时，相关存在、成员类型和可调用事实必须失效。具体行为由[字典语义](../semantics/5-dictionarySemantics.md)定义。

## 字典视图来源

来源进入索引签名位置同时受 TypeScript strict 源码兼容与运行时能力约束：

| 来源                       | 结论                           |
| -------------------------- | ------------------------------ |
| 原生字典                   | 直接使用或形成只读视图。       |
| 匿名精确对象、精确对象别名 | 相关成员兼容时形成零复制视图。 |
| `interface`                | 必须显式声明索引签名。         |
| `class`                    | 必须显式声明索引签名。         |
| 数组                       | 只能形成只读数值索引视图。     |
| 函数、基础值、原生标量     | 不能形成字典视图。             |

可写视图要求可能命中的固定成员均可写；含只读固定成员的来源只能形成只读视图。

```ts
type User = {
  name: string;
};

const user: User = { name: 'Tom' };
const dict: { [key: string]: string } = user;

dict.city = 'Shanghai';
dict === user; // true
dict.name = 'Jerry';
user.name; // "Jerry"
user.city; // 编译错误
```

动态写入不扩大其他别名的静态精确形状。

类方法和其他成员必须满足索引值约束。函数值不能作为字典；不支持混合调用签名与索引签名的可调用对象。

数组只读视图持有数组对象引用，不缓存元素缓冲区地址。可写数字字典会破坏数组稠密和删除规则，因此拒绝。

字典不能隐式转换为精确对象。需要精确形状时显式构造并逐字段读取。

## 字典间兼容

| 来源到目标                       | 结论                         |
| -------------------------------- | ---------------------------- |
| `StringDict<V> -> NumberDict<V>` | 允许。                       |
| `NumberDict<V> -> StringDict<V>` | 拒绝。                       |
| 可写字典值类型不同               | 拒绝，保持不变。             |
| 可写到对应只读字典               | 允许。                       |
| 目标有必需固定成员               | 来源必须静态保证存在并兼容。 |
| 来源有额外固定成员、目标仅索引   | 允许，保留底层身份。         |

兼容转换只允许直接复用来源或固定大小 `DictionaryRepack`，不能逐条复制、重哈希或执行运行时存在检查。

## 只读与方差

| 转换                                        | 结论                            |
| ------------------------------------------- | ------------------------------- |
| `MutableDict<V> -> ReadonlyDict<V>`         | 零复制允许。                    |
| `ReadonlyDict<V> -> MutableDict<V>`         | 拒绝。                          |
| `MutableDict<Dog> -> MutableDict<Animal>`   | 拒绝。                          |
| `MutableDict<Animal> -> MutableDict<Dog>`   | 拒绝。                          |
| `ReadonlyDict<Dog> -> ReadonlyDict<Animal>` | 仅在表示与 ABI 完全兼容时允许。 |

可写字典值类型不变。只读协变不能引入读取转换、接口打包、装箱或运行时检查。

## 属性访问与特殊 key

字典支持点访问、字面量索引和动态索引：

```ts
dict.name;
dict['name'];
dict[key];
```

点访问与字符串字面量索引使用同一规范 key。已知 key 可以使用固定成员约束；动态 key 执行字典查询。

`"__proto__"`、`"constructor"` 和 T49 定义的其他原型敏感 key 在字典中是普通数据 key。源码静态出现或有限联合包含这些 key 时，编译器给出与 JavaScript 行为不同的兼容性警告；宽字符串不增加运行时特殊检查。

不支持 symbol 索引、动态原型、属性描述符或 Proxy。

## Checker 职责

- 规范化键域、值类型、权限和固定成员。
- 检查字符串与数值签名重叠。
- 推导宽计算 key 的确定值类型。
- 计算缺失读取类型和存在性事实。
- 检查写入、删除、来源兼容、字典间兼容和方差。
- 记录固定成员与动态写删的别名失效范围。
- 产生明确的创建、打包、重打包、读取、写入、删除、存在和迭代操作。

lowering 不能重新执行结构兼容，也不能把缺失读取改写为原生零值。

## 与 TypeScript 的类型差异

| 场景             | TypeScript strict                    | Nxts                                                         |
| ---------------- | ------------------------------------ | ------------------------------------------------------------ |
| 未知 key 读取    | 默认常为 `V`                         | 强制 `V \| undefined`，等价启用 `noUncheckedIndexedAccess`。 |
| 对象进入索引签名 | 匿名对象可结构兼容，接口和类要求签名 | 保持接受边界并形成零复制视图。                               |
| 别名动态删除     | 通常不使其他别名事实失效             | 按 T58 失效相关事实。                                        |
| symbol 索引      | 支持                                 | 当前拒绝。                                                   |
| 函数动态属性     | 可表达部分混合类型                   | 函数不能作为字典。                                           |
| 字典原型成员     | 普通对象通常继承                     | 纯字典没有继承原型成员。                                     |

Nxts 保持 TypeScript strict 的静态子集。

[T40](./26-typeOperators.md) 定义 `keyof` 和索引访问类型；[T41](./27-advancedTypes.md) 定义 `Record<K, V>` 和映射类型。

## 诊断与类型测试

| 场景                        | 预期                     |
| --------------------------- | ------------------------ |
| 宽计算字符串或数值 key      | 推导确定值类型的字典。   |
| 上下文空字典                | 创建原生空字典。         |
| 精确对象进入字典位置        | 零复制并保持身份。       |
| 类或接口显式索引签名        | 形成字典视图。           |
| 数组进入只读数值视图        | 零复制读取。             |
| `hasOwn` / `in` 后读取      | 稳定路径收窄为 `V`。     |
| 未检查缺失读取作为 `V` 使用 | 编译错误。               |
| 不兼容重叠签名              | 编译错误。               |
| 类或接口缺少索引签名        | 编译错误。               |
| 可写数组字典视图            | 编译错误。               |
| 只读字典写入或删除          | 编译错误。               |
| 静态重复规范 key            | 编译错误。               |
| 原型敏感静态 key            | 编译通过并警告行为差异。 |
