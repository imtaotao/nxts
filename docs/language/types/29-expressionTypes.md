## 本篇范围

- 小节结论：已定

当前列入的运算符如下。未列入的运算符即使语法接受，也不得按本篇给出合法结果类型。

| 列入          | 形态                               |
| ------------- | ---------------------------------- |
| 一元 `-`      | 非直接负数字面量：`-value`、`-(1)` |
| 一元 `+`      | 已是数值的操作数；结果保持该类型   |
| 一元 `!`      | 条件兼容操作数，结果 `boolean`     |
| 一元 `void`   | 结果 `undefined`                   |
| 一元 `typeof` | 结果为对应字符串字面量或字面量联合 |
| 二元算术      | `+`、`-`、`*`、`/`、`%`            |
| 字符串 `+`    | 按 T13 分类为拼接时                |
| `++` `--`     | 可写数值左值；结果保持该类型       |
| 关系比较      | `<` `<=` `>` `>=`，结果 `boolean`  |
| 严格相等      | `===` `!==`，结果 `boolean`        |
| `&&` `\|\|`   | 值选择；保守结果见下               |
| `??`          | 空值合并，按 T14                   |
| `?:`          | 条件表达式；`lub` 两支             |
| 逗号          | 结果为最后一个操作数的类型         |
| `in`          | 结果 `boolean`                     |
| `instanceof`  | 结果 `boolean`                     |
| `**`          | 本版本编译错误                     |

| 未列入                                      | 原因                                                 |
| ------------------------------------------- | ---------------------------------------------------- |
| `delete`                                    | 可删除性由对象、字典、数组规范检查，入口属 T51 / T52 |
| `&` `\|` `^` `~` `<<` `>>` `>>>`、`==` `!=` | 语法阶段拒绝                                         |

求值顺序、短路和回绕不在本篇。对应语义文档 `19-expressionSemantics.md` 待建立。

## 期望类型

- 小节结论：已定

运算符的期望类型来自赋值注解、实参位置或另一已定型操作数。未定型数字字面量可以采用该期望类型，且必须落在范围内。已挂钩的变量不因期望类型改写。

```ts
const n: i32 = 1 + 2; // i32
const wide: u64 = 1 + 2; // u64
const increment = (count: u64) => count + 1; // u64
```

两侧都未定型且没有外层期望类型时，各字面量按 T08 默认基础类型，再要求两侧相同：

```ts
const sum = 1 + 1; // i32，不是 2
1 + 2.5; // 编译错误：i32 与 f64
```

`1 + 2.5` 若外层期望为 `f64`，两侧字面量都采用 `f64`，结果为 `f64`。

## 直接负数字面量

- 小节结论：已定（T20）

Babel 里 `-1` 是一元负号加上正数字面量。checker 在字面量候选阶段把它收成负数字面量，再按默认类型或期望类型做范围检查。

`-value`、`-(1)` 和其他非直接形式按普通一元 `-` 检查，即使之后能折成常量，也不形成负数字面量类型。

## 一元 `-`

- 小节结论：已定（T08）

| 操作数                            | 结果       |
| --------------------------------- | ---------- |
| 有符号整数（`i8`…`i64`、`isize`） | 保持该类型 |
| `f32` / `f64` / `number`          | 保持该类型 |
| `usize`、无符号整数               | 编译错误   |
| 非数值                            | 编译错误   |

未定型数字字面量落在直接负数字面量时不走本表。

## 一元 `+`

- 小节结论：已定

只接受已经是数值的操作数，结果保持该类型。不执行 JavaScript `ToNumber`。

| 操作数                                   | 结果                            |
| ---------------------------------------- | ------------------------------- |
| 整数、平台整数、`f32` / `f64` / `number` | 保持该类型                      |
| 未定型数字字面量                         | 采用期望类型或 T08 默认基础类型 |
| `string`、`boolean`、对象及其他          | 编译错误                        |

```ts
const n: u64 = +1; // u64
+'1'; // 编译错误
```

## 二元算术

- 小节结论：已定（T08、T12）

`+` 必须先按 T13 唯一分成数值加法或字符串拼接。本节只处理加法。

已经确定类型的操作数必须相同。不同宽度、符号性、`number` 与原生浮点之间不隐式转换。

| 两侧类型                             | `+` `-` `*` `/` `%` 结果 |
| ------------------------------------ | ------------------------ |
| 同一整数类型（含 `usize` / `isize`） | 该整数类型               |
| 同一 `f32` / `f64` / `number`        | 该浮点或 `number`        |
| 一侧或两侧为未定型字面量             | 按期望类型采用后再用上表 |
| 其他组合                             | 编译错误                 |

结果是基础类型，不是新的源码级字面量。负数不能采用无符号期望类型，只有 `-0` 可以按无符号零接受。

```ts
const increment = (count: u64) => {
  const next = count + 1; // u64
  const invalid = count + -1; // 编译错误
};

const mix = (small: i32, large: i64) => {
  small + large; // 编译错误
};
```

## 字符串 `+`

- 小节结论：已定（T13）

至少一侧为 `string` 或字符串字面量，且另一侧属于 T13 列出的单一静态类别时，结果为 `string`。`symbol`、函数和不能唯一确定转换路径的联合 / 泛型编译错误。

`+` 左结合，每个子表达式独立分类：

```ts
1 + 2 + '3'; // "33"
'1' + 2 + 3; // "123"
const text = 'a' + 'b'; // string，不是 "ab"
```

## `**`

- 小节结论：已定

本版本编译错误。语法接受该运算符，但不给出结果类型。原生整数或浮点幂运算若要支持，必须先补操作数、范围和结果类型，不能按 `number` 的 `**` 冒充。

## 一元 `!`

- 小节结论：已定（T07）

操作数必须是条件兼容表达式。结果类型为 `boolean`。不把操作数转成 `boolean` 再取反；truthiness 只用于选值。

## 恒真与恒假

- 小节结论：已定（T07、T10）

逻辑运算符按值选择，结果类型先判断左侧是否静态恒真或恒假。T07 只允许排除 `null` / `undefined`，不推导非零数值或非空字符串。

| 类别 | 类型                                                                                               |
| ---- | -------------------------------------------------------------------------------------------------- |
| 恒假 | `null`、`undefined`、字面量 `false` / `0` / `0.0` / `""` / `NaN`                                   |
| 恒真 | 字面量 `true`、非零 / 非空字面量、对象、接口、类实例、数组、元组、函数、`symbol` / `unique symbol` |
| 不定 | `boolean`、`string`、`number`、定宽与平台整数、`f32` / `f64`、枚举、以及含恒假或不定成员的联合     |

`unknown` 不能直接用于 `!`、`&&`、`||` 或条件位置。含 `null` / `undefined` 的联合按不定处理，结果保留这些成员；不因真分支可排除空值而把整个联合当成恒真。

## `&&` 与 `||`

- 小节结论：已定

两侧都要是条件兼容表达式。结果是被选中的那一侧的值的类型，不是 `boolean`。

设左侧为 `L`、右侧为 `R`：

| 左侧 | `L && R` | `L \|\| R` |
| ---- | -------- | ---------- |
| 恒假 | `L`      | `R`        |
| 恒真 | `R`      | `L`        |
| 不定 | `L \| R` | `L \| R`   |

```ts
const name = input || 'anonymous';
const user = ready && currentUser;
```

`ready: boolean` 且 `currentUser: User` 时，`ready && currentUser` 为 `boolean | User`。不能收成 `false | User`，因为 T07 不把 `boolean` 收成字面量。

短路求值见布尔语义。本篇不改求值顺序。

## `??`

- 小节结论：已定（T14）

`??` 按空值判断，不按 truthiness。结果为 `lub(NonNullish(L), R)`。左侧静态不含空值时结果为 `L`；左侧静态只含空值时结果为 `R`。

```ts
name ?? 'default'; // name: string | null → string
0 ?? 10; // i32，不是 10
```

## 条件表达式

- 小节结论：已定（T04、T07）

`cond ? left : right` 的条件位置与 `if` 相同，接受 T07 的 truthiness，不要求 `boolean`。结果为 `lub(typeof left, typeof right)`。两支各自接收外层期望类型。

```ts
const label = ok ? 'on' : 'off'; // "on" | "off"；let 时 widening 为 string
```

## 关系比较

- 小节结论：已定（T07、T08、T13、T21、T39）

`<`、`<=`、`>`、`>=` 的结果为 `boolean`。不执行隐式 `ToNumber` / `ToPrimitive`。

| 两侧类型                           | 结果      |
| ---------------------------------- | --------- |
| 同一整数、`f32` / `f64` / `number` | `boolean` |
| 两侧都是 `string` 或字符串字面量   | `boolean` |
| 数字枚举与 `i32` / 同一枚举        | `boolean` |
| 字符串枚举与 `string` / 同一枚举   | `boolean` |
| 未定型字面量采用期望类型后落入上表 | `boolean` |
| 联合且各成员共享同一比较实现       | `boolean` |
| 其他组合                           | 编译错误  |

`i32 < i64`、`string < number`、`boolean`、对象、`symbol`、`unknown` 以及不同枚举之间的关系比较都是编译错误。联合必须在编译期选到唯一实现，不能按 tag 动态分派。

## 严格相等

- 小节结论：已定（T07、T08、T13、T14、T17、T18、T21、T39）

`===`、`!==` 的结果为 `boolean`。`==`、`!=` 由语法拒绝。

| 两侧                                             | 处理                                             |
| ------------------------------------------------ | ------------------------------------------------ |
| 同一数值类型、同一 `string`、同一 `boolean`      | 按值比较                                         |
| 一侧为 `null` 或 `undefined`                     | 允许；另一侧即使不含该空值也合法，可折叠但不收窄 |
| 对象、数组、元组、函数、类实例、接口、字典       | 比较引用身份                                     |
| 同一枚举，或枚举与对应底层值                     | 按规范值比较                                     |
| 宽 `symbol` 与 `unique symbol`                   | 运行时身份比较；宽侧保持 `symbol`                |
| 两个静态已知且不同的 `unique symbol`             | 编译错误                                         |
| `unknown` 与 `unknown`，或 `unknown` 与空值      | 允许                                             |
| `unknown` 与普通非空值                           | 普通一侧须先显式打包                             |
| 联合                                             | 至少存在一组成员类型规范允许的比较，否则编译错误 |
| 不同宽度或符号性的数值、不同枚举、无可比较成员对 | 编译错误                                         |

```ts
value === null; // 允许
value === true; // value: string | i32 时编译错误
Ready === Failed; // 两个不同 unique symbol 时编译错误
```

该防御性空值规则不扩展为普通跨类型比较。收窄事实由 T06 / T14 定义，本篇只给表达式类型。

## `++` 与 `--`

- 小节结论：已定

操作数必须是可写数值左值。结果保持该数值类型。前缀与后缀的类型相同，求值差见语义规范。

写回枚举、非数值、只读或非左值都是编译错误。

## 逗号表达式

- 小节结论：已定

从左到右检查每个操作数。结果类型是最后一个操作数的类型。

## 一元 `void`

- 小节结论：已定（T15）

操作数按普通表达式检查。结果为 `undefined`。不把函数值变成 `() => void`。

## 一元 `typeof`

- 小节结论：已定（T14）

值位置 `typeof` 的结果是对应字符串字面量或字面量联合。标识符必须先绑定。`typeof value === undefined` 编译错误。类型位置的 `typeof` 见 T40，不是本运算符。

## `in`

- 小节结论：已定（T27）

结果为 `boolean`。左操作数必须是 `string`，不执行 `ToPropertyKey`。右操作数在求值前排除 `null` 与 `undefined`。字面量 key 的折叠与收窄见对象语义和 T06。

## `instanceof`

- 小节结论：已定（T36）

结果为 `boolean`。右操作数必须是类构造器值。普通函数、对象、接口和不能证明为类构造器的联合都是编译错误。成功分支的收窄见 T24。

## Checker 职责

checker 必须：

1. 把每个 `+` 唯一分类为数值加法或字符串拼接。
2. 把期望类型传给未定型数字字面量，再检查范围。
3. 要求已定型算术操作数相同，结果保持该类型。
4. 把直接 `-1` 收成负数字面量，把 `-value` / `-(1)` 按一元 `-` 检查。
5. 拒绝一元 `+` 的非数值操作数和所有 `**`。
6. 按恒真 / 恒假 / 不定给出 `&&` / `||` 的结果，按 T14 给出 `??`，按 T04 合并 `?:` 两支。
7. 把 `!`、关系比较、严格相等、`in`、`instanceof` 标为 `boolean`。
8. 按上表拒绝没有可比较实现的关系比较和严格相等。
9. 检查 `++` / `--` 的可写数值左值，把 `void` 标为 `undefined`，把逗号标为末项类型。

checker 不因折叠把 `1 + 1` 写成字面量 `2`，不选择机器宽度或 LLVM 类型。

## 诊断与类型测试

| 场景                                          | 结果                           |
| --------------------------------------------- | ------------------------------ |
| `const n: i32 = 1 + 2`                        | 接受，结果 `i32`。             |
| `const n: u64 = 1 + 2`                        | 接受，结果 `u64`。             |
| `const sum = 1 + 1`                           | 接受，结果 `i32`。             |
| `count + 1` 且 `count: u64`                   | 接受，结果 `u64`。             |
| `i32 + i64`                                   | 拒绝。                         |
| `1 + 2.5` 无期望类型                          | 拒绝。                         |
| `const x: f64 = 1 + 2.5`                      | 接受，结果 `f64`。             |
| `count + -1` 且 `count: u64`                  | 拒绝。                         |
| `-value` 且 `value: i32`                      | 接受，结果 `i32`。             |
| `-value` 且 `value: u32`                      | 拒绝。                         |
| `const min: i32 = -2147483648`                | 接受（负数字面量）。           |
| `'a' + 1`                                     | 接受，结果 `string`。          |
| `1 + 2 + '3'`                                 | 接受，结果 `string`。          |
| `+"1"`                                        | 拒绝。                         |
| `2 ** 3`                                      | 拒绝。                         |
| `!value`                                      | 接受，结果 `boolean`。         |
| `ready && user` 且 `ready: boolean`           | 接受，结果 `boolean \| User`。 |
| `input \|\| 'anonymous'` 且 `input: string`   | 接受，结果 `string`。          |
| `null && x`                                   | 接受，结果 `null`。            |
| `obj && x` 且 `obj` 为对象                    | 接受，结果为 `x` 的类型。      |
| `name ?? 'default'` 且 `name: string \| null` | 接受，结果 `string`。          |
| `0 ?? 10`                                     | 接受，结果为 `0` 的类型。      |
| `ok ? 'on' : 'off'`                           | 接受，结果 `"on" \| "off"`。   |
| `count > 0` 且 `count: i32`                   | 接受，结果 `boolean`。         |
| `i32 < i64`                                   | 拒绝。                         |
| `'a' < 'b'`                                   | 接受，结果 `boolean`。         |
| `'a' < 1`                                     | 拒绝。                         |
| `value === null`                              | 接受，结果 `boolean`。         |
| `value === true` 且 `value: string \| i32`    | 拒绝。                         |
| `++count` 且 `count: i32`                     | 接受，结果 `i32`。             |
| `++state` 且 `state` 为枚举                   | 拒绝。                         |
| `void save()`                                 | 接受，结果 `undefined`。       |
| `key in obj` 且 `key: string`                 | 接受，结果 `boolean`。         |
| `value instanceof Dog`                        | 接受，结果 `boolean`。         |
| `value instanceof User` 且 `User` 为接口      | 拒绝。                         |

## 依赖关系

- T05、T08、T13、T20 提供字面量、数值和拼接规则。
- T07、T10、T14 提供 truthiness、短路、`??` 和空值比较。
- T04 合并 `?:` 与不定逻辑运算的两侧。
- T21、T18、T39 提供联合、symbol 与枚举比较。
- T15、T27、T36 提供 `void`、`in`、`instanceof`。
- T03 检查运算符结果能否赋给注解或参数。
- T06 使用本篇给出的比较与逻辑表达式做收窄，不改写结果类型。
