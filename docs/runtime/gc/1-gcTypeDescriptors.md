# GC 类型描述与扫描

- 任务编号：T46
- 规范状态：讨论中
- 文档顺序：1

## 目标与边界

本规范把 T45 的 `LayoutRecord` 和 GC 形状编码为精确扫描描述，并定义移动、写屏障、安全点和内存耗尽边界。GC 不能重新决定对象字段、数组元素或联合成员的物理布局。

## 已确认上游约束

- 每个堆布局必须具有 GC 安全的初始化状态。
- 对象对 GC 可见前，全部引用区域必须处于可扫描状态。
- 标量区域不能误扫描为引用。
- inactive 联合引用 payload 必须清零或由状态描述明确排除。

## 数组

数组扫描必须满足：

- 只扫描 `[0, length)` 内的有效引用元素。
- 截断、`pop` 和清空后，旧引用不能继续保活对象。
- 引用元素写入使用必要的写屏障。
- 新分配且未发布的数组可以消除逐项屏障。
- 批量填充和复制可以使用批量屏障。
- 原生标量数组不得执行引用扫描或引用写屏障。
- 联合元素依据 T45 的状态平面只扫描当前有效引用成员。
- 增长必须先初始化新增引用槽位，再发布新的可扫描长度。

不可达的自引用或互相引用数组必须能够回收。

## 字符串

字符串值持有一个管理存储引用。存储中的 code unit 数据与哈希缓存不包含 GC 引用，不执行元素扫描或写屏障；字符串内容创建后不可变。

共享字面量和驻留存储按普通根或静态生命周期管理。短字符串内联、驻留和哈希缓存不能让 GC 把标量数据误识别为引用，也不能把内部数据指针暴露为稳定外部地址。

## 元组

固定元组为每个位置生成精确 GC 描述：

| 位置类型                   | 扫描规则                       |
| -------------------------- | ------------------------------ |
| 原生数值和 `boolean`       | 不扫描。                       |
| 对象、数组、元组和函数引用 | 扫描对应引用槽位。             |
| 接口值                     | 扫描底层对象引用。             |
| 联合值                     | 按 tag 或可空引用状态扫描。    |
| rest 区段                  | 按闭合元素类型和实际长度扫描。 |

引用位置写入执行必要写屏障；原生标量位置不得执行引用屏障。新分配且未发布元组的初始化可以合并或消除屏障。

GC 不能扫描未初始化槽位或超出实际长度的 rest 存储。自引用和互相引用元组按普通可达性回收，不使用引用计数。

## 类实例与描述符

类实例扫描必须满足：

- 按 T45 的基类段和派生类段扫描固定引用字段。
- 可选字段只在存在状态有效时扫描引用 payload。
- 动态扩展区域使用对应字典描述符扫描。
- 接口字段扫描底层对象引用。
- 捕获环境只在实际动态类描述符持有时扫描。
- 未使用动态字段或捕获能力的类不携带对应 GC 边。

构造期间，对象对 GC 可见前必须初始化全部引用槽位到安全状态。构造抛错且实例未泄漏时，部分实例可以正常回收；不要求隐式析构或 finalizer。

不可达循环类实例必须能够回收。Nxts 不提供手动 `free`、析构器、finalizer、WeakRef、FinalizationRegistry 或 `Symbol.dispose` 类生命周期协议。

## 精确对象

对象扫描必须：

- 按 T45 的固定字段 GC 形状扫描引用。
- 只在可选属性存在时扫描对应引用 payload。
- 删除引用可选属性时清除 payload。
- 对已创建的字典扩展表增加对应 GC 边。
- 不扫描枚举描述符中的共享字符串和静态元数据为实例字段。

无可选属性和无动态扩展的普通对象不能承担额外扫描分支。对象在发布给 GC 前必须把全部引用槽位初始化到安全状态。

## 字典与扩展状态

字典扫描必须：

- 按闭合值类型扫描当前有效条目。
- 删除引用条目时清除可扫描槽位。
- 渐进扩容期间正确扫描旧桶和新桶。
- 扫描对象字典视图的 `dataRef` 与已创建扩展表。
- 区分接口有限扩展记录和字典任意 key 扩展描述。

按对象身份附着的稀疏扩展状态表不能阻止对象回收。弱键、ephemeron 或等价机制由 T46 最终定稿。

## 递归对象图

运行时对象图可以自引用或互相引用。不可达循环必须能够回收，因此 GC 不能只依赖简单引用计数。

GC 描述按有限布局记录引用槽位：

- 对象与类实例记录固定引用偏移。
- 数组和字典复用闭合元素类型或值类型的扫描描述。
- 联合依据 tag 或可空引用状态只扫描当前有效 payload。
- 接口扫描底层对象引用，静态 witness 元数据不作为实例字段扫描。
- 闭包环境和捕获字段由 T58 的闭包描述确定。

扫描器沿运行时引用遍历实际对象图，不递归生成无限静态描述。递归类型声明本身不能增加对象字段、引用计数、父指针或运行时类型标签。

## 待确认项

- 描述符二进制编码。
- 移动与非移动回收策略。
- 安全点、根集合和栈映射。
- 写屏障和批量屏障入口。
- 弱引用、ephemeron 和 finalization 边界。
- 内存耗尽的统一 runtime 失败入口。
