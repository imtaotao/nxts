# 类运行时

- 来源能力：T36、T45
- 规范状态：已定稿
- 文档顺序：5

## 目标与边界

本规范定义类实例分配、运行时类身份、描述符、方法派发、静态状态和动态类物化。静态规则由[类类型](../../language/types/23-classTypes.md)定义，可观察行为由[类语义](../../language/semantics/7-classSemantics.md)定义，物理布局由[类型运行时表示](../../compiler/representation/1-typeRepresentation.md)定义。

类运行时必须消费 T45 的规范布局，不能使用另一套动态对象 shape 代替固定类布局。

## 类模板与运行时身份

实现区分类静态模板和每次求值的运行时身份：

```text
ClassTemplate {
  fixedLayout
  gcShape
  instanceMethodSlots
  staticMemberSchema
  constructionSummary
}

RuntimeClass {
  identity
  template
  staticState
  captureEnvironment?
}
```

模块级无捕获类可以使用静态描述符，不要求堆分配。局部类和类表达式只有在类身份、静态状态或捕获环境可观察时才物化 `RuntimeClass`。

不同类求值可以共享布局模板和方法代码，但不能合并构造器身份、静态状态或捕获环境。

## 实例分配

类实例采用稳定管理引用。逃逸实例进入 GC 管理堆；不逃逸实例可以栈分配、标量替换或完全消除。

优化必须保持：

- `===` / `!==` 身份。
- 基类、接口和其他别名观察到的共享写入。
- 构造与字段初始化顺序。
- 反射、枚举和动态类身份。
- 构造异常和循环引用回收。

静态 `new C(...)` 不得分配额外构造器对象、动态实参数组或通用构造分派器。通过类型安全构造器变量执行 `new` 使用一次类型化间接调用。

## 字段访问与动态扩展

固定字段访问使用 T45 确定的常量偏移，不执行哈希或 shape 查找。派生类到基类转换保持同一对象地址。

具有 T30 显式索引签名的类可以拥有独立动态扩展区域：

- 动态扩展不能改变固定字段偏移。
- 整条继承链最多使用一个有效动态扩展定位。
- 未使用动态字段能力的类不能携带动态字典状态。
- 动态成员查找和枚举复用字典运行时契约。

## 实例方法派发

| 接收者事实                      | 运行时路径                       |
| ------------------------------- | -------------------------------- |
| 具体类且目标唯一                | 直接调用。                       |
| 基类接收者但目标可证明唯一      | 去虚拟化为直接调用。             |
| 基类接收者且存在多个覆盖        | 从固定方法槽位执行一次间接调用。 |
| private 方法或 `super.method()` | 直接调用静态目标。               |
| 真正多态接口调用                | 一次 witness 间接调用。          |

方法槽位使用展平继承表，调用成本不随继承深度增加。已知访问器目标直接调用并允许内联。

派生箭头函数字段覆盖普通方法时，槽位可以指向静态 thunk。只捕获接收者且 `readonly` 的字段可以消除函数对象或字段间接层；mutable 函数字段必须保留可观察字段读取和函数身份。

## 接口视图

每个“具体类实例类型 + 规范接口契约”共享一份 witness table。类实例转换为接口视图：

- 保留底层对象身份。
- 不扫描成员。
- 不裁剪或复制对象。
- 不要求堆分配。

已知具体目标可以去除接口打包或 witness 调用。

## 静态状态与派发

静态字段属于运行时类身份。模块级静态类通常使用固定模块存储；动态类的静态状态属于对应 `RuntimeClass`。

继承静态字段需要“读取继承值、首次派生写入创建自身字段”的存在状态。只有实际使用静态字段继承的类才承担该状态成本。

静态方法和访问器使用独立静态槽位：

- 已知类调用直接解析。
- 构造器变量调用按真实类描述符选择一次静态槽位。
- `super.staticMember` 直接访问静态父成员。

静态初始化降低为类初始化函数。模块级类只执行一次；局部类和类表达式每次求值执行本次类身份的初始化。初始化完成后的普通静态访问不保留初始化函数调用。

## 捕获环境

局部类方法捕获外层变量时，类描述符持有 T58 定义的环境。多个实例共享同一次类求值的捕获环境，不为每个实例重复创建类环境。

循环中反复创建并逃逸的类保留每次求值的身份和环境成本。非逃逸且身份不可观察的局部类可以完全静态化。

## `instanceof`

动态类检查使用实际类描述符和祖先摘要：

- 已知类检查可以常量折叠或降低为固定身份比较。
- 动态构造器检查不读取 `.prototype`。
- 不调用 `Symbol.hasInstance`。
- 不执行字符串比较、字段扫描或可修改原型链遍历。

## 失败原子性

构造或静态初始化表达式抛出异常时，运行时停止后续初始化。未泄漏的部分实例不返回给调用方，最终由 GC 回收；不执行隐式字段回滚、析构或 finalizer。

类布局、方法表或构造 ABI 指纹不匹配必须在链接或模块加载前失败。

## 性能验收

| 常见路径          | 要求                                   |
| ----------------- | -------------------------------------- |
| 静态 `new C(...)` | 无额外构造器对象或通用参数数组。       |
| 固定字段访问      | 常量偏移，无哈希或 shape 查找。        |
| 已知方法和访问器  | 直接调用并允许内联。                   |
| 派生类到基类      | 不复制、不分配、不调整地址。           |
| 类到接口          | 不裁剪；witness 打包不要求堆分配。     |
| 可选字段          | 已证明状态时消除分支。                 |
| 未使用动态能力    | 不携带动态字典、捕获环境或静态存在表。 |

性能基准至少覆盖实例分配、固定字段、直接与虚调用、接口调用、动态构造、静态继承、深继承、动态类身份和循环引用 GC。

第一版可以接受整体吞吐约为等价 Go 实现的 50%，但普通类不能采用统一装箱、哈希字段访问、强制堆分配或通用调用分派器。
