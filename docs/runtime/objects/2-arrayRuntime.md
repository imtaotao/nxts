# 数组运行时

- 来源能力：T34、T45
- 规范状态：已定稿
- 文档顺序：2

## 目标与边界

本规范定义普通数组的分配、容量增长、截断、批量复制和运行时辅助算法。数组静态类型由[数组类型](../../language/types/21-arrayTypes.md)定义，可观察行为由[数组语义](../../language/semantics/6-arraySemantics.md)定义，公开方法由[数组标准库](../../stdlib/2-array.md)定义，物理布局由[类型运行时表示](../../compiler/representation/1-typeRepresentation.md)定义。

运行时必须消费 T45 的规范布局，不能建立另一套数组对象或元素表示。

## 身份与缓冲区

数组值是稳定的管理引用。赋值、参数传递和返回只复制引用；扩容可以替换元素缓冲区，但不能改变数组对象身份。

普通访问通过规范元素布局定位。数组不使用运行时写时复制、动态 elements-kind、逐元素反射、通用值装箱或可修改原型链。

## 分配

- 已知最终长度的字面量、`repeat`、`generate`、spread 和组合操作应一次分配。
- 未知长度构建使用几何扩容，`push` 均摊 O(1)。
- 小数组可以把对象头与数据区放在同一分配中，但访问路径不能增加可观察分支。
- 空数组保留独立对象身份，可以共享只读空数据区。
- 非逃逸数组可以由优化器栈分配、标量替换或完全消除。

字节数计算必须使用 checked `usize`。长度、容量或分配大小溢出时，在修改任何可观察状态前失败。

## 增长与截断

增长步骤必须满足：

1. 验证新长度不超过 `i32::MAX`。
2. 验证容量和分配字节计算不溢出。
3. 必要时分配新缓冲区并复制有效元素。
4. 初始化新增元素槽位。
5. 最后发布新缓冲区、容量和长度。

任一步失败都不能发布部分初始化状态。

`pop`、截断和 `length = 0` 可以保留容量。超出新 `length` 的旧引用必须从 GC 可扫描集合移除，不能继续保活对象。容量不可通过语言观察，运行时可以在内存压力下释放保留缓冲区。

## 复制与批量操作

- 布局相同的连续元素区域使用批量复制。
- `Array.from(source, mapper)` 的 mapper 结果直接写入目标数组，不创建中间数组。
- `flatMap` 不创建中间 `map` 数组。
- spread、`concat` 和已知层级 `flat` 在可以计算结果长度时一次分配。
- 新分配且未发布的引用数组可以消除逐项写屏障。
- 引用批量填充和复制使用 T46 定义的批量屏障。
- 原生标量数组不得执行引用写屏障。

复制消除或缓冲区转移只能在新数组身份、别名和写入都不可观察时执行。

## 边界检查优化

运行时入口接受已经由 Typed IR 明确的索引、长度和元素布局。后端可以：

- 消除控制流已证明安全的边界检查。
- 把数组联合 tag 和元素平面基址提升到循环外。
- 对同构数组生成专用循环。
- 在证明结构不变时缓存长度和缓冲区。

运行时不得通过动态元素检查弥补 checker 或表示阶段缺失的类型信息。

## 失败原子性

| 场景             | 要求                               |
| ---------------- | ---------------------------------- |
| 动态越界写入     | 抛出 `RangeError`，数组保持不变。  |
| 长度负数或增大   | 抛出 `RangeError`，数组保持不变。  |
| 增长超过最大长度 | 抛出 `RangeError`，数组保持不变。  |
| 容量字节数溢出   | 与超长创建相同。                   |
| 真实内存耗尽     | 由 T46 定义统一 runtime 失败入口。 |

## 性能验收

数组实现以等价 Go 程序为基准，最终目标达到 Go 数组或切片核心路径水平。第一版可以接受核心吞吐约为等价 Go 实现的 50%，但不得存在阻止继续优化的动态表示。

| 场景                            | 必须测量                       |
| ------------------------------- | ------------------------------ |
| `i32[]`、`f64[]` 顺序读写       | 吞吐、边界检查消除和代码大小。 |
| 已知与未知长度构建              | 分配次数、复制量和尾延迟。     |
| `map`、`filter`、`reduce`       | 回调内联、结果分配和循环融合。 |
| 引用数组                        | GC 扫描时间和写屏障成本。      |
| 联合元素数组与数组联合          | tag 成本、分支提升和循环吞吐。 |
| `slice`、spread、concat         | 分配数和批量复制吞吐。         |
| stable `sort` 与 `sortUnstable` | 比较器内联、辅助内存和吞吐。   |
| 非逃逸小数组                    | 栈分配、标量替换和零分配结果。 |

基准必须同时报告吞吐、分配次数、分配字节、峰值内存和延迟。
