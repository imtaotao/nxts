# 对象运行时

- 来源能力：T26、T27、T45
- 规范状态：已定稿
- 文档顺序：3

## 目标与边界

本规范定义固定对象分配、描述符查询、可选属性状态、枚举状态和按需动态扩展。对象类型由[对象类型](../../language/types/15-objectTypes.md)定义，可观察行为由[对象语义](../../language/semantics/4-objectSemantics.md)定义，物理布局由[类型运行时表示](../../compiler/representation/1-typeRepresentation.md)定义。

## 描述符

对象运行时消费两类共享描述符：

```text
StorageDescriptor {
  propertyIdentity
  fieldOffset
  optionalState
  gcShape
}

EnumerationDescriptor {
  initialPropertyOrder
  compactPropertyId
  arrayIndexClassification
}
```

存储描述符由规范对象布局共享。布局相同但初始枚举顺序不同的分配点可以使用不同枚举描述符。描述符不为每个实例复制。

普通字段读写使用常量偏移，不查询描述符。描述符只服务 GC、显式反射和动态能力。

## 可选属性状态

- 多个可选属性共享紧凑存在位。
- 读取缺失属性返回 `undefined`。
- 写入缺失属性设置存在位并更新枚举状态。
- 删除清除存在位和引用 payload。
- 普通无可选属性对象不携带存在位成本。
- 普通字段读写不读取枚举顺序。

缺失属性首次存在的顺序使用紧凑属性编号维护，不创建动态属性哈希表。

## 动态名称查询

动态 `in` 和 `Object.hasOwn` 查询只读名称索引：

- 固定必需成员可以直接命中。
- 可选成员进一步检查存在位。
- 联合值先按规范判别选择描述符。
- 接口值查询底层具体对象描述符。
- 类实例查询动态类描述符。

名称查询不得分配内存或创建实例属性表。实现可以使用共享哈希表、完美哈希或其他只读结构，但不能改变枚举顺序和成员身份。

## 枚举

枚举遍历：

- 共享枚举描述符中的初始属性。
- 当前存在的可选属性。
- 实例紧凑首次存在顺序。
- 已形成字典视图时的动态扩展条目。

数组索引形式键按数值排序；静态属性字符串直接复用共享值。`for...in` 不分配 key 数组，`Object.keys` 分配独立结果数组。

## 字典视图

精确对象进入 T30 字典位置时：

- 保持固定字段前缀与对象身份。
- 视图转换不复制、不扫描字段，也不分配哈希表。
- 首次新增动态 key 时按需创建扩展表。
- 固定成员和动态成员共同参与反射与枚举。

只有可能使用可写字典能力的分配点或声明类型才需要扩展状态定位。未使用字典能力的对象不增加普通字段访问分支。

## 分配与优化

每次可观察对象字面量求值创建独立实例。不逃逸对象可以栈分配、标量替换或完全消除。

优化不得改变：

- 引用身份和别名写入。
- 属性存在状态。
- 属性首次存在与枚举顺序。
- 反射结果数组身份。
- 动态扩展对原对象身份的可见性。

## 性能要求

- 固定字段读写达到接近 Go 结构体字段访问成本。
- 未使用反射的对象不执行名称哈希或描述符分支。
- 未使用可选属性的对象不携带存在状态。
- 未使用字典视图的对象不分配扩展表。
- 已知形状反射可以专门化。
- 动态计算 key 的字典路径以同键域 Go map 为目标，不要求达到固定字段成本。
