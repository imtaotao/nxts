# 接口 Runtime

- 来源能力：T29、T45
- 规范状态：已定稿
- 最后更新：2026-07-28
- 文档顺序：7

## 目标与边界

本规范定义接口 witness、有限可选属性扩展和动态契约查询。静态结构匹配归 checker，物理视图布局归 T45。

## Witness

每个“具体类型 + 规范接口契约”共享一份只读 witness，不为每个实例复制。witness 提供：

- 固定字段偏移或访问器。
- 可选属性存在位与扩展槽位。
- 写入入口及写屏障类别。
- 方法入口和闭合泛型方法槽位。
- 具体类型和目标契约指纹。

成员按规范键与成员种类分配槽位，不按源码或继承顺序。

## 有限可选属性扩展

可写可选属性按以下优先级实现：

1. 具体对象已有兼容槽位时直接使用。
2. 分配点和接口用途可见时，在对象创建时预留紧凑槽位与存在位。
3. 来源布局不能修改时，首次写入创建附着于对象身份的有限扩展记录。

扩展记录：

- 只保存契约允许的有限属性。
- 由预计算槽位访问，不扫描成员名。
- 被所有接口视图与对象反射共享。
- 保持属性首次出现和重新添加顺序。
- 提供精确 GC 描述。

接口转换本身不能创建扩展记录。任意键字典扩展由 T30 独立管理，不与有限接口槽位混淆。

## 方法调用

普通接口方法使用预计算入口。方法级泛型的类型实参在调用点闭合；链接阶段只为程序实际使用的闭合签名建立固定槽位，不在运行时传递类型参数或执行类型哈希查找。

具体类型与 witness 已知时，优化器可以去虚化并内联。

## 动态契约查询

`unknown` 或较宽接口到目标接口的受信检查查询具体类型描述与预生成 witness。查询不扫描字段，不调用用户代码，不临时合成契约。

## 性能验收

至少测量打包、复制、字段读写、可选属性固定槽位与首次扩展、方法调用、泛型方法闭合槽位、动态查询和去虚化。普通固定对象访问不能因存在接口能力而增加分支。
