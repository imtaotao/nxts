# 字典运行时

- 来源能力：T30、T45
- 规范状态：已定稿
- 文档顺序：4

## 目标与边界

本规范定义原生哈希表、对象字典视图、按需扩展状态、哈希安全、扩容和 GC 集成。静态类型由[字典类型](../../language/types/18-dictionaryTypes.md)定义，可观察行为由[字典语义](../../language/semantics/5-dictionarySemantics.md)定义。

## 两种来源表示

```text
NativeDictionary {
  fixedNonIndexPrefix?
  typedHashTable
}

DictionaryView {
  dataRef
  dictionaryWitness
}
```

`DictionaryWitness` 提供固定成员查询、动态扩展定位、枚举和底层身份访问。形成视图时不扫描字段、不复制对象，也不分配堆内存。

抽象边界使用统一视图 ABI。来源静态已知时可以去除 witness，直接进入原生哈希或固定字段路径。

## 对象扩展状态

首次新增动态 key、覆盖固定成员或动态删除时才创建扩展状态。扩展状态保存：

- 动态条目。
- 固定成员 shadow。
- 删除 tombstone。

所有别名和接口视图共享同一对象身份的扩展状态。

局部分配点可以直接提供扩展定位。跨模块封闭布局没有内联定位时，可以使用按对象身份附着的稀疏表；表项仍只在首次动态写删时创建，且不能让视图转换本身分配。

接口有限扩展记录与字典任意 key 扩展可以共享身份附着机制，但必须具有独立类型描述、权限和 GC 边界。

## 哈希表契约

| 方面     | 约束                                                          |
| -------- | ------------------------------------------------------------- |
| 复杂度   | 查找、写入和删除平均 O(1)。                                   |
| 哈希安全 | 缓存进程密钥字符串哈希，再混合每表 salt；异常碰撞强化重哈希。 |
| 扩容     | 渐进迁移或等价有界工作，避免一次搬迁全部条目。                |
| 删除     | 不因单次删除立即缩容或整理全表。                              |
| 字面量   | 已知条目数预估容量，静态 key 预计算哈希。                     |
| 小字典   | 允许内联小表、栈分配、标量替换或消除。                        |
| 值存储   | 具体 `V` 直接存储，不逐值装箱。                               |
| 数值 key | 常见非负整数不分配格式化字符串。                              |

## 枚举状态

JavaScript 枚举顺序使用紧凑插入序号或等价元数据。没有可观察枚举、rest、spread 或反射的非逃逸字典可以消除顺序元数据。

普通查找不为数值 key 排序付费。`Object.keys` 可以在结果数组中完成数值索引排序，`for...in` 使用栈或临时状态，不强制产生 GC 堆数组。

## 存储与 GC

值类型 `V` 在布局前闭合：

- 原生标量直接存储。
- 引用值按静态 GC 描述扫描。
- 联合值使用规范联合布局。
- 不统一装箱为 JavaScript value。

删除引用条目必须清除可扫描槽位。渐进扩容期间旧桶和新桶都必须具有精确扫描描述。

按对象身份附着的稀疏扩展表不能阻止对象回收；具体弱键、ephemeron 或等价机制由 T46 定稿。

## 性能目标

| 路径             | 目标                                     |
| ---------------- | ---------------------------------------- |
| 原生字典动态查找 | 最终达到 Go map 同数量级和常见路径水平。 |
| 对象视图固定 key | 未受重叠副作用时恢复固定偏移。           |
| 对象视图未知 key | 平均 O(1)，允许有界描述符与扩展表分支。  |
| 未使用字典能力   | 不增加动态查找、哈希分配或字段分支。     |

性能测试分别测量原生字典、固定 key 视图、未知 key、首次扩展、稳定扩展、删除、枚举和非逃逸小字典。
