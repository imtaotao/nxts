# Symbol Runtime

- 来源能力：T18
- 规范状态：已定稿
- 最后更新：2026-07-28
- 文档顺序：1

## 目标与边界

本规范定义 symbol 身份分配和模块值传递。静态 `unique symbol` 身份由 checker 管理，标量布局由 T45 管理。

## 身份分配

runtime 使用不可伪造且在进程生命周期内不复用的 `SymbolId`。`Symbol()` 通过线程安全计数器或等价机制生成新身份，目标为 O(1)。

无可观察描述时不得仅为 symbol 身份分配堆对象。描述可以存入按需调试侧表；优化构建可以不保留。

身份空间耗尽时必须在复用 ID 前产生资源耗尽失败。

## 模块身份

模块顶层 symbol 声明按 ESM 初始化规则执行一次。运行时导出值传递同一 `SymbolId`；导入方的静态声明身份由模块元数据关联，不通过运行时字符串名称恢复。

整数、外部指针和普通 FFI 数据不能伪造 symbol。未来宿主桥接必须提供受检身份映射。

## 性能验收

创建为 O(1)，复制和相等为标量操作。`unique symbol` 不增加 tag 或包装；未使用 symbol 的程序不链接 registry、侧表或协议代码。
