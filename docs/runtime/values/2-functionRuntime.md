# 函数值 Runtime

- 规范状态：已定稿
- 实现状态：未实现
- 最后更新：2026-07-28
- 文档顺序：2
- 覆盖能力：T32、T33

## 目标与边界

本规范定义函数值身份、描述符和类型化入口的 runtime 契约。静态函数关系由 [`20-functionTypes.md`](../../language/types/20-functionTypes.md) 定义，物理字宽由 [`1-typeRepresentation.md`](../../compiler/representation/1-typeRepresentation.md) 定义，闭包环境由 T58 定义。

## 逻辑结构

```text
FunctionValue
├─ stableIdentity / environment
└─ typedCallEntry

FunctionDescriptor
├─ primaryEntry
├─ demandedAlternateEntries
├─ name
└─ length
```

实现可以从函数实例读取描述符入口，也可以使用紧凑的“环境引用 + 代码入口”视图，但必须满足：

- 函数值大小固定，GC 能准确识别环境引用。
- 不同类型化入口保持同一稳定身份。
- 精确签名直接调用不要求物化函数值。
- 间接调用使用已知物理签名，不经过通用动态分派器。

## 身份与描述符

严格相等比较稳定身份，不比较当前 ABI 入口或仅比较代码地址。无捕获顶层函数可以使用共享静态身份；实际执行的闭包创建仍须获得独立身份。

`name`、`length` 和受信动态检查信息存放在共享描述符中，不为每个闭包复制静态名称。动态计算名称只在实际参与函数创建的路径保存实例数据。

## 调用路径

| 场景                     | Runtime 路径                               |
| ------------------------ | ------------------------------------------ |
| 已知顶层函数直接调用     | 直接调用静态入口，不物化函数值。           |
| 顶层无捕获函数作为值     | 使用共享静态函数实例或等价固定表示。       |
| 已知对象方法直接调用     | 显式传递接收者，不创建绑定闭包。           |
| 未知具体目标的函数值调用 | 从函数值取得类型化入口并执行一次间接调用。 |
| 参数或返回 ABI 适配      | 调用按需静态入口，不创建动态实参数组。     |

不逃逸与逃逸闭包的环境分配由 T58 决定。runtime 不提供 `arguments` 对象、运行时签名检查或重载候选表。
