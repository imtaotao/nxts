# Runtime

本目录定义生成程序依赖的内存管理和运行时语言机制。

| 子系统       | 职责                                               | 入口                                  |
| ------------ | -------------------------------------------------- | ------------------------------------- |
| 内存         | 分配、对象生命周期和资源失败边界                   | [`memory`](./memory/index.md)         |
| GC           | 精确扫描、回收、屏障、安全点和弱引用               | [`gc`](./gc/index.md)                 |
| 运行时对象   | 字符串、数组、对象、字典、类、接口和动态描述符支持 | [`objects`](./objects/index.md)       |
| 运行时基础值 | symbol、函数值和多态函数值的 runtime 支持          | [`values`](./values/index.md)         |
| 异常         | 错误对象、抛出、捕获和栈展开                       | [`exceptions`](./exceptions/index.md) |
| 异步         | Promise 状态、任务调度和异步执行                   | [`async`](./async/index.md)           |
