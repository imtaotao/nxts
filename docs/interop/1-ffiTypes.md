# 原生内存与 FFI 类型

- 任务编号：T48
- 规范状态：讨论中
- 文档顺序：1

## 目标与边界

本规范将定义外部类型、所有权、生命周期、原生内存和宿主调用边界。当前只记录前置规范已经确定、T48 不能推翻的约束。

## 数值映射约束

平台整数只有在外部 ABI 明确兼容时才能映射：

| 外部语义                                                   | Nxts 候选 |
| ---------------------------------------------------------- | --------- |
| 无符号指针宽度整数，例如已验证的 `size_t`                  | `usize`   |
| 有符号指针宽度整数，例如已验证的 `ptrdiff_t` 或 `intptr_t` | `isize`   |

绑定必须同时验证：

- 宽度。
- 符号性。
- 对齐。
- 调用约定。
- 外部类型的真实语义。

不能仅因当前目标字节数相同，就把 C `long`、固定宽度整数或其他外部整数自动视为平台整数。

合法平台整数映射必须零运行时转换。需要跨目标稳定数据时使用明确固定宽度整数并显式转换。

## 枚举映射约束

外部整数或字符串不能无检查重解释为 Nxts 枚举。未来枚举 FFI 适配器必须：

- 验证外部底层宽度、符号性或字符串编码。
- 在进入安全 Nxts 值域前验证成员集合。
- 明确定义失败结果和调用 ABI。
- 不暴露内部空值 niche、联合 tag 或枚举静态元数据布局。

外部 ABI 已由绑定生成器证明只会产生合法成员时，可以生成受信静态适配器，但该证明和适配器身份必须进入绑定元数据，不能由普通源码断言替代。

## 待确认项

- 所有权、借用、生命周期和回调。
- 外部字符串、缓冲区和结构体布局。
- 错误、异常和线程边界。
- 与 runtime 私有 ABI 的适配层。
