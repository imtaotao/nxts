# 枚举标准库

## 目标与边界

本规范定义原始标量进入封闭枚举的检查转换，以及显式枚举成员遍历。行为已定稿；模块路径、公开名称和结果承载类型由 T49 最终确定。

## 检查转换

候选入口为：

```ts
import { tryToEnum } from 'std/enum';

function parseMode(raw: string): Mode | null {
  return tryToEnum<Mode>(raw);
}
```

规则如下：

- 类型参数必须是数字或字符串枚举；空枚举的检查转换签名由 T49 确定。
- 输入类型必须与目标底层类型一致。
- 匹配任一规范成员时返回目标枚举值。
- 不匹配时返回 `null`。
- 编译期已知输入直接折叠为成员或 `null`。
- 转换不得使用通用反射、动态类型描述或堆包装。

数字枚举可使用比较、范围、静态表或分支；字符串枚举可使用直接比较或静态哈希。检查成本只发生在显式边界，成功后的普通枚举操作不重复验证。

反序列化器必须复用相同的受信检查节点，不能通过普通断言绕过验证。

## 成员遍历

候选入口为：

```ts
import { enumValues } from 'std/enum';

const values = enumValues<State>();
// readonly State[]
```

`enumValues<E>()` 必须：

- 按声明顺序返回不同规范值。
- 重复值别名只返回一次。
- 返回共享只读静态数组，重复调用不分配。
- 对空枚举返回共享空数组。
- 只为实际使用该能力的枚举生成成员表。
- 数字表直接存储 `i32`，字符串表复用静态字符串常量。

名称和别名遍历属于独立的 `enumEntries` 候选能力，由 T49 决定是否提供。普通枚举值不因遍历能力默认携带名称。

## Intrinsic 约束

编译器按完成绑定的标准库符号身份识别 intrinsic，不按文本函数名匹配。用户定义的同名函数是普通调用。

成员表和检查表是按枚举共享的只读静态数据。未调用对应 API 时，链接产物不得仅为枚举声明保留运行时成员表。

## 诊断与测试

至少覆盖：

| 场景                  | 预期                         |
| --------------------- | ---------------------------- |
| 数字与字符串合法输入  | 返回规范枚举值。             |
| 非成员输入            | 返回 `null`。                |
| 编译期常量输入        | 常量折叠，不保留运行时检查。 |
| 重复值和空枚举遍历    | 去重并返回共享只读结果。     |
| 重复调用 `enumValues` | 不重复分配。                 |
| 未使用遍历 API        | 不生成成员表。               |
